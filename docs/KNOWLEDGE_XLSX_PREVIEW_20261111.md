问题与实现

小型 XLSX 原先走 Office 打印 PDF 预览。用户提供的《桌面研究报告与建议书内容模板.xlsx》因此被拆成 27 页，宽表、长文字和合并区域的阅读效果与 Excel 工作表差别较大。

本次增加只读工作表布局接口：company_sheet_layout.py 使用 openpyxl 读取列宽、行高、合并区域、隐藏行列、字体、富文本、填充色、边框和对齐方式；前端 KnowledgeSheetViewer 用带 rowspan/colspan 的固定布局表格显示。列宽根据工作簿默认字体的数字宽度转换，行高保留点数，单元格内容不会反向撑高源行。

支持工作表切换、原始比例、适合宽度、缩放和区域内横向滚动。完整原件阅读与解析片段检索继续独立；不把检索片段当作原件排版。原件不重写，公式不执行，有缓存结果时显示结果，没有结果时明确提示。保持逐次权限校验、预览审计、账号/时间/追踪水印和 private/no-store 响应。

范围和边界

- 本次原样式预览用于小型、没有嵌入图片/图表/绘图的 XLSX；解压大小上限 64 MiB。
- 超过 10,000 行、256 列或单表 200,000 单元格的工作簿继续使用有界分页表格，避免完整实例化大表。
- 带图片、图表或绘图的其他小型工作簿继续使用现有 PDF 预览，不宣称复杂 Excel 图形效果已支持。
- 当前支持常见数值/日期格式，不是完整的 Excel 排版或计算引擎。字体缺失时浏览器会回退，不能保证不同操作系统逐像素一致。
