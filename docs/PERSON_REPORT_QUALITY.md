## 工作流与归因

人物研究计划持久化全部15章任务，实质章节2—12都有独立查询与中英文主题映射，支持显式姓名别名和英文中间名首字母。检索仍采用现有多引擎与权威源适配；关联企业分别进行一跳采集，不递归扩大到所有股东、子公司和投资企业。用户提供的关联关系保持待核验，不自动提升为已证实控制关系。

清洗保留来源陈述、原文摘录、事件时间、发布时间、采集时间、身份与主体范围。身份不匹配或低置信材料隔离。原文可用时，改写事实不能引入原文没有的说法；恢复原文中的有效摘录，或记录拒绝原因。重复事实去重；无关材料不填充章节；研究截止日之后的已知发布日期材料不进入本轮判断。没有明确事件时间时不把发布日当事件日。来源等级不是事实正确性的保证。

每条实际陈述获得稳定事实级E-ID。2026-10-21起，章节研究池保留全部通过主体、时间、相关性和去重规则的材料，不再按每章12条、单来源3条或单域名4条限制研究输入。存在可分析材料时，全部合格研究池（含归属明确的公司、他人、观点背景）按约14000字符分批研读，超长单条独立成批，不截断原句。只有背景记录的章节及风险登记按原文字段确定性处理，不为了形式制造人物分析。公司、他人和观点材料不能支持个人能力或信用推断。已识别的同一事件取值冲突保留双方证据，不择一断言。低曝光人物不需要凑足旧的24条事实门槛；没有资料时生成明确的核验计划，不能生成确定结论。

章节研究池完整不等于原始来源已经用足。`person_retained_material`逐条访问留存来源，记录原文可用性、身份、发现线索、完整目标姓名陈述、既有事实覆盖及补入情况；不再只依赖上游已经抽出的事实卡。扫描保留完整原段或完整句，专门识别人物资料页连续字段；既有事实包含的相同原句不重复补入。新闻索引、相关标题、截断摘要、低身份置信及失败获取仍不变成事实。仅为口碑发现采集的原文可补充有归属的背景，但未经专门事件、评价者和行为主体校验的补充记录不得用于个人判断。专业结构化来源继续走原有适配器，保留全部合格返回记录。`scripts/audit_person_source_use.py`逐来源对照实际研究批次、确定性处理与正文引用，分别列未用原因；不同URL不冒充独立印证。

专业平台按企业和工具记录 returned、failed、not_queried 等状态；额度不足、鉴权失败及访问失败是采集缺口。模型写作同样记录调用及拒绝原因，额度/鉴权错误开启本轮熔断。具体异常不会被改写成人物或企业无记录。

## 写作和交付

执行顺序为2—12 → 13综合评估 → 1摘要 → 14来源索引 → 15核验计划。摘要与综合评估只能使用前文实际引用的材料。写作模型返回结构化陈述及单独的分析，事实陈述必须能定位到本章事实卡，不允许以真实编号给新编事实背书。新增数值、明显确定性断言及外部拉丁实体等检查是保守的自动保护，不能替代语义复核。

研究取材与正文篇幅分别控制。多批材料先研读再综合，正文合并重复判断，原则上每章最多3条简短分析；示例原文默认最多4条、合计约1600字符，单条原文不强行截断。事实库与逐批输入台账保留，正文引用只统计实际出现的E-ID。研读请求返回只证明材料送达及接口返回，不证明每条材料已充分理解、独立核实或实际用于结论。2026-10-21的同材料局部回放见[完整取材与精简写作验证](PERSON_COMPLETE_MATERIAL_REVIEW_20261021.md)，尚未完成所有章节的真实内容验收。

各章保留来源事实、主体和时期边界、初步研究判断、专项覆盖问题。公司业绩、司法记录、信用状态不能直接变成人物能力或个人责任。模板中的健康、婚姻和职业画像是待核查方向，不是根据身份或资料缺失作负面判断的依据。没有可复核评分量表时人物能力与品行不自动评分；未知项不转换为低风险或高风险。

第14章只从第1—13章实际E-ID反查来源，允许同一来源支持多个章节，不再事后分配一批来源充当正文引用。Word保留证据编号跳转和原始HTTP链接；structured://只表示平台记录定位，不能当成可公开访问网页。第15章确定性汇总并去重各章缺口、冲突、模型和平台阻碍。

后台写作使用主线程固定的项目和来源快照，避免ORM懒加载跨线程访问；写作结束再回写诊断。清洗、报告及身份规则版本已升级，人物续跑需要重建正文引用索引。`person_claim_ledger`以JSON保存事实、拒绝记录、逐章诊断、API状态、依赖产物ID和报告摘要值。首次生成与续跑导出均保持未人工复核状态；程序运行完成与可正式交付是不同状态。
