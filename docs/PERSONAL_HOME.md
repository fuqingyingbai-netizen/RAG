# 个人首页

登录、注册成功或带有效登录凭证重新打开网站，默认进入“个人首页”。临时密码账号先完成密码修改，再进入首页；正常修改密码时保持当前页面。

首页提供：

- 我的任务、进行中、已完成、待处理四项概况。
- 最近更新的6个个人任务，可直接打开任务管理中的对应行；已有搜索和分页不会遮住目标任务。
- 最近6项报告与建议书，每个项目的每类成果仅展示最新版本。支持下载或进入任务详情查看；待复核、建议书待确认、Word 导出异常等标记继续显示。
- 新建任务、任务管理、复核和资料入口；管理员另有账号管理快捷入口。

普通用户与管理员的首页均只统计本人创建的项目和相关成果。管理员进入“任务管理”后沿用原有管理权限，能够查看全部有权管理的项目。姓名仅用于本人问候，账号备注保持管理员可见范围。

“进行中”依据当前后端进程实际登记的运行任务判断；中断的历史阶段记录计入待处理，不会仅凭数据库的阶段字符串显示正在执行。统计使用现有单进程工作流运行状态，沿用本地服务的部署方式。已完成表示工作流完成，成果的复核状态另行展示。

首页打开时加载，在浏览器页面可见期间每30秒刷新，也可手动刷新。加载失败显示错误；刷新失败时保留上次数据并明确标识。首次加载失败时不显示虚假的零统计。离开首页会停止其自动刷新。

后端接口为 `GET /research/home`，复用现有账号、项目和成果表，使用当前登录账号做归属筛选，只返回概况、最近任务和成果摘要，不返回报告正文或启动研究工作流。下载及任务详情沿用现有鉴权接口。
