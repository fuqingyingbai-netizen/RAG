# 博查充值后联通与三家检索互补实验

## 结论

博查充值后使用项目现有密钥成功返回搜索结果。Exa、Tavily同轮均返回。8组问题中，三家各自发现了另两家本次Top5未返回的相关原始页面，建议保留三家能力，并在完整人物研究中按问题和证据缺口使用。该实验不证明每个查询必须三家全开，也不证明三家能覆盖所有人物或全部公开/付费来源。

本次另修复博查网站过滤参数和网页乱码/检测页误判；尚未实施新的预算、缓存及自动路由策略。人物报告所有章节的完整真实验收仍未完成。

## 方法与调用账本

时间：2026-10-20，结果包含各次请求时间。样本包含Seed官网、吴永辉中文组织报道、邓范鑫技术会议、英文人物报道、王传福教育履历、Lisa Su海外履历、Tianqi Chen研究项目、石扬播客8组。前4组有指定域名，后4组为开放搜索；每家每组最多5条，不是完整索引召回。

先执行24次生产适配器搜索，发现博查旧网站过滤失效，再进行5次原生过滤/对照查询（其中1次为AMD正控制），最后1次验证修复后的生产多引擎入口。另有1次充值后连通测试。合计搜索请求31次：博查15、Exa8、Tavily8。抽选19个原始页面使用同一抓取器检查；修复解码后仅复测受影响的4页，共23次抓取操作。抓取操作可能内部尝试桌面、移动等方式，23不是底层HTTP次数。

发现阶段仅在实验进程关闭博查自动抓取，避免URL去重前逐条重复抓取；没有修改.env。Exa与Tavily保留当前生产参数并随搜索返回其抽取内容，因此三者返回文本长度和响应时间不可直接作公平的全文质量或延迟排名。

原始响应、原生参数复测、抽选原文及测试XML均位于被Git忽略的work/reference-source-audit/three-engines。核心结果为comparison-native.json；保留原results.json作为修复前基线。公开HTML只展示状态、标题、URL、方法与边界，不公开完整原文或密钥。

## 已修复的实际接入问题

1. 博查旧适配器只拼接site:操作符。4个受限问题的18条结果全部落在限定站点之外。原生include复测后返回遵守站点限制的结果（官网题为0条），AMD正控制能返回官网资料。已将单引擎和multi两条入口改为传include/exclude，新增两模式回归；生产multi入口实际复测通过。
2. 网页HTTP响应无charset时，requests常默认Latin-1，原代码保留该默认编码，导致部分UTF-8中文乱码。现按明确HTTP charset、HTML meta、UTF-8与后备识别解码。受影响校方页面和技术会议页面已恢复姓名及正文。
3. 一个36氪安全检测页此前因乱码未被识别，错误标为done。解码和检测短语修复后明确标为blocked_or_challenge，不进入正文。Apple播客URL本次仍返回不含目标的通用页面；没有把它算作修复成功或人物证据。

首次19页抽查中15项状态为done，只有11项命中预期姓名或主题锚点。4个问题页复测后，两页恢复中文、一页改判阻断、一页仍不匹配。关键词命中仅是诊断，不能代替主体、时间和陈述级核验；这些刻意抽样数据也不是总体抓取成功率。

另发现Tavily播客结果带回约158万字符RSS，不适合原样进入模型上下文。应先定位目标单集，再保留相关内容；此项裁剪尚未在生产实现。

验证：检索入口、域名参数、人物工作流及研究策略相关71项回归通过；git diff --check通过。未将实验当作完整15章人物报告验收。

## 费用与后续使用

已读取用户提供的博查官方计费页，Web Search API目录价为0.036元/次，也提供资源包。按目录价估算，本轮15次博查搜索为0.54元；实际扣费受资源包影响，以账户账单为准。Tavily本轮8次advanced按当前官方规则对应16积分；未查询其账户实际扣费。Exa本轮8次搜索同时请求内容及摘要，未捕获费用明细，不将基础搜索单价冒充总费用。

建议三家保留，完整研究按任务分工覆盖；一般问题先主引擎，身份/来源/时间缺口触发补查，重要问题选不同引擎寻找独立原始信源。已知URL直接获取，企业和人物商业关系调用企查查。共享查询与原文缓存、预算、转载识别、单集裁剪仍是后续优化项，目前生产multi仍会并发调用被允许且已配置的引擎。旧进程中的403隔离状态可能仍存在，需要后端进程重新加载后才使用修复和新状态。
