# 公司报告检索与交付改进进度（2026-10-27）

当前保存的是通用公司报告链路的开发进度，**真实报告尚未通过最终交付验收**。Git 集成、测试通过及模型返回有效内容均不能替代报告验收。

## 已实现

- 按用户选定形式输出分析主报告、完整证据 HTML 附件及两者组成的 ZIP。完整证据保留原文、字段、出处及处理去向。
- 正文与附件的取舍由两次完整原文审阅决定；主报告事实选择继续保留限定条件、相反信息、主体及期间。结构化核心事实不裁剪。
- 事件提取检查事实、责任与影响、日期含义、程序与收款状态、相反证据、义务承担主体六项条件。没有有效独立审稿的候选不能获得准入。
- 修正空引号占位、原文信息 ID 混用、逐字定位失败及责任否定句的误判；肯定表述仍须有原文支持。
- 本轮实际模型记录暴露了主报告事实选择回执的序列化问题：相同字段值经排序存储后，提示词哈希会因字段顺序不同而变化。新合约 `company-main-focus-v2-canonical-input-witnesses` 对范围及完整输入使用固定 JSON 顺序。旧 V1 回执保留，但不得伪装成新合约已通过的审稿。
- 当前报告版本为 `company-report-evidence-v148-canonical-focus-witnesses`。生产判断规则不以验收公司的名称或具体金额硬编码。
