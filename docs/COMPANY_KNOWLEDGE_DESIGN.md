# 公司知识库：Knowledge Universe

2026-11-03，基于远端 main 的最新系统外壳，为研究首页、资料库、研究问答、案例库提供完整的白天/夜晚视觉系统。所有装饰图形由 CSS 与 SVG 绘制，无新增框架、运行依赖、外部图片或模型调用。

| 页面 | 布局与视觉 | 保留的业务行为 |
| --- | --- | --- |
| 研究首页 | 网格底纹、缓慢移动的知识轨道、深色问题入口、项目统计与经验卡片 | 按真实可访问资料统计；查案例和比较资料各自进入对应流程 |
| 资料库 | 默认文件卡片、按格式着色的立体图标、悬停反馈、卡片/列表切换与清晰状态标签 | 标签/时间/项目组合筛选、跨页选择、固定表头和分页、原件阅读与管理 |
| 研究问答 | 私有研究空间、近期会话入口、资料叠层图形、三种问题建议、独立问题与答案区域 | 服务端历史恢复、检索范围、流式进度、表格、引用核对、错误和停止状态 |
| 案例库 | 文档网格封面、音频波形、视频播放符号；独立的空档案引导画面 | 案例分类、筛选、上传、阅读、播放、说明检索和属性编辑 |

上传、管理、权限审批、音视频阅读与引用核对弹窗跟随当前主题，共享控件和反馈规则。PDF 原件的图像颜色保持原貌。桌面上将系统使用帮助移到左侧，避免遮挡资料分页和问答发送按钮；移动端放入顶部导航区域。

## 资料库文件展示（第二轮）

参考 [Spacedrive SpaceUI](https://github.com/spacedriveapp/spaceui) 的 FileGrid、KindIcon、TagPill 与 FileList 组织思路，改为默认卡片浏览，并保留表格供密集核对使用。Word、PDF、表格、演示文稿、图片、音视频与文本分别使用颜色和图形表达类型；这些是格式示意封面，不伪造文件缩略图或内容摘要。实际名称、项目、标签、说明、状态与时间取自目录数据，说明为空时不生成虚构文字。

选中态、收藏、标签筛选、阅读、管理、失败重试和权限申请直接在卡片操作；卡片/列表切换保留已选资料，展示偏好按账号保存，不改变问答的证据范围。布局随窗口调整列数，底部操作不随正文增多而被裁掉；文件列表继续独立滚动。所有效果沿用现有 Vue/CSS，无新增依赖。

## 文件样式统一与白天/夜晚主题

资料卡片、案例文档封面、首页最新资料/继续阅读，以及问答中的引用文件与已选文件，复用 `KnowledgeFileArtwork` 图形组件。首页采用紧凑卡片、引用与问答范围采用小卡片；案例仍保留音频波形与视频播放图形。栏目共用格式色、文件折角、标题层次和交互反馈。

知识库顶部使用单个太阳/月亮图标按钮切换主题（aria-pressed），不显示主题文字，悬停与辅助技术可获得切换说明。首次默认白天，与系统浅色工作界面协调；手动选择保存在浏览器 localStorage，离开后再进入仍恢复。存储不可用时仍可切换。主题只在知识库挂载期间作用于其内容页面及弹窗；系统侧栏、Logo、账号顶栏在两种主题间保持原样，不参与切换。离开时清除根主题属性，其他功能保持原有系统外观。

浅色模式采用独立的冰蓝/淡紫背景、白色文件卡片、清晰的描边和青色选中状态，加强分区与文件的对比，不复刻系统全局浅色样式。CSS 将面板、文字、边框、强调、状态和阴影收敛为白天语义色变量，既有夜晚色值保留为各规则的回退值。没有用滤镜反色，不改变 PDF、图片、视频的原始内容像素。原生下拉、日期、音频控件同步 color-scheme。两种主题共用结构、业务状态和数据，不通过重建会话切换主题。

## 动效与可访问性

导航提供“暂停动效/开启动效”按钮，并正确设置 aria-pressed。操作系统的 prefers-reduced-motion 会禁用装饰动画及过渡。所有装饰图形和图标对辅助技术隐藏，按钮仍有明确名称与焦点轮廓。颜色使用青色和紫色作为强调，处理失败、受限、可检索仍有文字标签。

空列表、空案例库、未创建会话、引用、模拟连接中断、上传进度与管理表单都有独立显示状态。文件名、标签、说明及模型答案继续使用 Vue 文本绑定，表格单元格不执行 HTML。

## 参考与边界

参考 [Onyx](https://github.com/onyx-dot-app/onyx) 的知识问答工作区组织方向和 [Magic UI](https://github.com/magicuidesign/magicui) 的轻量图形动效思路，采用原创 Vue 模板、CSS 与 SVG 实现，未复制组件源码或品牌素材。既有项目导航、登录页与其他研究功能继续使用 main 上的系统外壳。

## 项目目录工作区

项目卡片、子目录和文件各自表达清晰的层次：项目入口的“创建项目”打开设置面板并创建空目录，进入后才出现“新建目录”“上传文件”。面包屑可返回任意上层；“浏览全部文件”提供跨项目筛选、收藏与比较。首页的项目卡片打开对应目录，项目没有文件时也会显示。

参考 [Spacedrive SpaceUI](https://github.com/spacedriveapp/spaceui) 的路径导航与文件工作区组织，以及 [Motion Primitives](https://github.com/ibelick/motion-primitives) 的展开式界面动效方向。以原创 CSS 透视文件夹、盖板和纸张图形实现开盒：悬停微开、点击展开，内容随后浮现。项目/目录/文件设置及阅读弹窗使用短暂的透视展开。保留减少动态效果偏好及现有暂停按钮，无新增 React 或动画依赖。

项目编辑面板左侧显示文件夹与项目背景，右侧填写属性；上传面板显示当前归档路径与继承信息，再选择文件并可选填写说明。新文件的设置聚焦文件名、归档目录和说明，继承属性在项目设置里修改。浅/深色主题均覆盖此流程，系统侧栏、顶栏不参与主题切换。

## 首页知识导航与栏目分类

首页将研究入口和知识导航并列，原本孤立的轨道装饰改成由项目档案、研究成果、经验沉淀、方法模板环绕的动态分层核心。四个节点显示当前账号可访问的数据并可进入对应栏目；底部状态带可进入可检索、待复核或处理异常的资料。没有异常时禁用对应入口；只有处理中资料时进入其中一种处理状态。概览不冒充知识关系图、AI 推荐或实时使用统计。

个人工作台改为紧凑的项目入口，避免重复用文件数量绘制进度条；项目空间复用文件夹开盒图形。深浅主题共享结构，动态支持暂停和减少动态效果偏好。视觉方向参考 Onyx 的研究工作区和 Motion Primitives 的轻量空间层次，以现有 Vue、CSS 和 SVG 原创实现，无新增依赖。

创建项目的分类跟随入口：资料库为项目原件、研究成果、访谈纪要、行业资料；案例库为项目经验、案例复盘、方法与模板、培训分享。在某个分类下创建时默认选择该分类。编辑已有项目按项目原有分类所属栏目提供选项，即使从全项目视图进入也不会丢失案例分类。上传继续继承项目属性，旧文件的属性管理保持兼容。

企业级能力的缺口与优先级单独记录于 [能力对照](COMPANY_KNOWLEDGE_ROADMAP.md)。

本轮验证：44 项前端检查通过；浅/深色各 30 张浏览器截图，运行错误为零。新增覆盖首页节点跳转、两个入口的分类隔离、在资料库编辑案例项目时保持分类、分类默认值及手机项目封面的宽度与图形边界。后端与数据库未改动。
