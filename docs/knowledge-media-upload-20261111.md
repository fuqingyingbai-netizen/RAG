# 知识库图片、音视频与上传体验修复

2026-11-11。更新 main，未部署线上。同步保留 main 的目录回收修复与远端 Ragas 优化。

## 修复结果

| 问题 | 当前行为 |
|---|---|
| 大文件只有“上传中”，无法判断进展 | 显示真实传输进度、大小、速度和耗时；传输结束明确进入“服务器保存中”，收到保存回执后才显示已保存 |
| 上传弹窗一直挡住操作 | 可收起、从页面浮动入口重新打开；完成后保留结果入口。后台编辑其他资料不会改变正在上传批次的位置与说明 |
| 停止、失败容易误以为没保存 | 传输中可停止；服务器保存中不伪装成可撤销。可停止剩余文件，失败保留重试；连接中断明确提示保存结果待核对，不自动重复 POST |
| 图片预览被水印任务挡住 | 图片预览、下载和封面不再进入水印队列，下载保留原始字节和文件名；支持缩放和适应宽度 |
| 音视频打开要等完整加水印、完整接收 | 独立准备无水印播放版本，按文件内容版本缓存；上传后尝试预热，普通 H.264 视频优先快速整理封装，其他视频转兼容 MP4，其他音频转 MP3 |
| 播放拖动和授权 | 原生播放器按 HTTP Range 分段读取，支持普通、开放结尾及后缀范围与 HEAD；每次读取检查账号、权限、删除状态和文件版本 |
| 播放失败一直空等 | 区分准备、加载、缓冲和失败，提供重试播放及下载原文件；准备轮询有上限，关闭阅读器后停止轮询 |
| 音视频出现解析搜索和空片段栏 | 默认隐藏文档解析控件；长说明才出现“查找说明”。有说明时明确根据说明提问，无说明时显示补充入口；侧栏按内容收紧，手机端不保留空播放器高度 |
| 音视频地址又被当成图片 | 修复互斥渲染分支；旧图片、旧媒体的延迟错误不会清空新打开的预览 |

图片、录音、视频不叠加身份水印或语音身份提示。登录、资料访问权限、下载和预览审计保留；其他文档继续遵循其水印导出规则。音视频仍只检索人工说明，没有新增自动转写。

## 边界

- 未上线，未进行线上带宽与并发压测；不能保证所有网络、所有录制编码的首开耗时。
- 首次兼容版本准备仍可能等待，后续打开可复用缓存。FFmpeg 沿用已有依赖；缓存目录默认 `data/company_media_cache`，可用 `COMPANY_KNOWLEDGE_MEDIA_CACHE` 指定，准备新文件时清理超过一天未使用的播放缓存。
- 上传仍为单请求传输；刷新、退出或断网可能中断，失败后从头重试，未新增分片断点续传。已收到服务器保存回执的文件不会因点击停止而被删除。
- 播放授权使用一小时、HttpOnly、同站且限定单文件路径的 cookie，不把登录令牌放到播放 URL。账号禁用、令牌版本变化、权限撤回和资料删除会阻止后续分段读取。
