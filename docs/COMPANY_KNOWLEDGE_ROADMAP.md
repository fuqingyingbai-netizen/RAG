# 企业知识库能力对照与建议

评估日期：2026-11-03。范围为本仓库的公司知识库、项目目录、权限审批、文件处理及研究问答。

当前已经具备项目与多级目录、标签与时间筛选、文档解析与 RAG、引用原文、问答记忆、原件下载、音视频归档播放、单独授权与权限审批、失败重试、同名文件版本号。下一阶段应优先提高知识质量、可恢复性和日常维护效率。

| 优先级 | 能力 | 当前状态与建议 |
| --- | --- | --- |
| P1 | 知识负责人、定期复核和失效管理 | 已有手动复核状态；补充复核人、复核时间、下次复核日期、提醒与归档状态。历史结论保留出处，过期资料明确提示。 |
| P1 | 操作审计与删除恢复 | 已有审批记录，删除后保留受控原件；尚无完整的知识库操作审计与回收站恢复流程。记录谁下载、改名、修改权限或删除，提供管理员恢复与保留期限。 |
| P1 | 整个项目目录导入与批量整理 | 目前支持项目内多文件上传和逐个目录管理；补充保留层级的目录导入、上传队列、失败续传、批量移动、批量标签。针对既有本地项目目录最有直接价值。 |
| P2 | 搜索与回答质量反馈 | 已有问答与引文；补充“有用/无用”、错误原因、无答案问题汇总、检索命中率与失败分析，形成可处理的知识缺口。不能用文件数量代替使用效果。 |
| P2 | 版本历史与协作 | 已有文件版本号；补充版本时间线、旧版查看和恢复、变更说明、评论、提及、订阅项目更新。收藏和最近阅读目前主要保存在浏览器，可改为账号服务端同步。 |
| P2 | 结构化经验沉淀 | 案例库已有分类与文件归档；补充复盘模板（背景、问题、做法、结果、适用条件、教训）及引用关联，让案例不止是附件。 |
| P3 | 数据源连接与组织管理 | 按公司实际资料分布，逐步接入共享盘、飞书、企业微信或现有文档平台，并同步源权限、更新和删除。统一登录、部门/项目组及离职权限回收需要结合现有身份系统确认后规划。 |
| P3 | 音视频内容检索 | 当前仅用户填写的说明进入检索；可选增加转写、时间戳引用、字幕和章节定位。原有音视频上传、播放、下载可独立使用。 |

建议顺序：先完成复核责任、回收站与审计、目录批量导入；再做反馈统计和版本协作。备份需要同时覆盖数据库和原件，并实际演练恢复，不能仅依赖保留原件。

## 对照来源

- [Confluence 知识库](https://www.atlassian.com/software/confluence/knowledge-base)：结构化目录、模板、权限、版本和文件预览。
- [Confluence 功能](https://www.atlassian.com/software/confluence/features)：协作、通知、归档及使用分析。
- [Guru 内容验证](https://help.getguru.com/docs/verifying-and-unverifying-cards)：知识负责人、验证状态、验证周期和提醒。
- [Glean 搜索权限](https://docs.glean.com/administration/search/faq)：检索遵守源系统权限。
- [Glean 反馈机制](https://docs.glean.com/administration/assistant/configuration/feedback-data-handling)：搜索和回答反馈及相应分析数据。

上述优先级是结合本系统用途和现有实现作出的建议；本次交付实现的是首页和分类体验调整，表中的后续能力尚未新增。
