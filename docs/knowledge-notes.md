# 经验沉淀：图文笔记

在「经验沉淀」点击「新建图文笔记」。在本人项目内新建会保存在当前目录；
在根目录新建会归入本人「随手记录 · 待整理」项目。「我的笔记」可以继续编辑草稿
和已发布笔记；已发布文件的「编辑信息」和阅读窗口的「编辑笔记」也能返回编辑器。

## 写作与保存

- 支持三级标题、粗体、斜体、下划线、有序和无序列表、引用、表格及撤销/重做。
- 表格中按 Tab 移动；选中单元格后出现加行、加列、删除和合并/拆分工具。
- 可以选择图片、粘贴截图或拖入 PNG/JPG/WebP。失败的图片有重试和移除入口。
- 插图后光标自动进入下方正文，可直接继续打字。填写图片说明后，点击
  「在图片下继续写正文」返回正文；图片说明与正文分开填写。
- 图片可以拖动右下角缩放，或选择宽度百分比；图片说明随正文检索。
- 点击「识别图片文字」使用本地 OCR，结果可校正；识别失败仍可手写说明。
  再次识别已有文字时会先确认，避免覆盖校正结果。
- 停笔约一秒后自动保存到服务器。状态明确区分等待、保存中、已保存、失败和冲突。
  关闭时先保存；失败时可以重试。本机恢复副本按账号、笔记分别保存，重开时可选择恢复。
  本机存储不可用时仍可下载 JSON 恢复副本；其用途是故障留存，不是公开的文档格式。
- 不提供多人实时协作；另一窗口修改后，版本冲突会阻止覆盖。可以留存本机内容、
  载入服务器版本后手动合并。

## 发布、权限和检索

草稿仅项目创建者和管理员可读写，创建人和修改人由后端采集。每次保存有版本号，
审计记录保存操作人、时间和修改前后内容。笔记继承项目权限、分类、行业、标签和保密等级；
普通账号只能编辑自己项目中的笔记。

点击「发布笔记」才生成归档 Word 并提交现有解析/索引流水线。
发布快照不可变，编辑草稿不会改变其他成员当前阅读的版本。新版本索引成功时原子切换
当前文件；失败时原有可检索版本仍可用，可重试同一发布任务而不重复创建文件。
第一版尚未索引成功时会显示等待或失败，不会宣称可检索。

正文、表格、图片说明及校正后的 OCR 文字进入 RAG，并沿用文件引用、权限过滤、
来源定位和原件预览。资料库与经验沉淀不跨库检索。OCR 文字需要作者核对，
系统不将其视为人工验证的事实。

## 导出和限制

- Word：可编辑正文、原生表格和内嵌图片，文档与图片均带下载身份标记。
- Markdown：ZIP 包含 note.md、images/ 和目录说明。正文、图片均有身份标记，
  保留相对路径即可在支持 Markdown 的软件查看。
- 原始图片保存在私有对象存储，预览也要鉴权并添加账号标记；静态目录不提供原图。
- 正文最多 2 MB，单张上传 12 MB / 4000 万像素，100 张图片；参与一次发布或导出的
  图片合计最多 32 MB，生成的发布文件最多 32 MB。单表最多 100 行、12 列。
- 外部网页图片不会热链进笔记，请下载后插入，避免链接过期或权限泄漏。
- 不包含在线共同编辑、自动音视频转写或 Word 文件的原位编辑。
