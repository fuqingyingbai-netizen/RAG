# 知识库业务流程检查（2026-11-10）

本轮覆盖资料库、经验沉淀的主要操作链。先定义业务规则，再使用 computer-use 浏览器中的 Playwright API 操作页面，使用 Schemathesis 4.33.1 和 Hypothesis 检查真实接口。测试使用独立数据库与样本文件；仅云端发现、索引和模型输出使用替身。正式数据库没有写入验收资料。

## 固定业务规则

- 总览提供行业、复核、日期筛选；进入项目及子目录后移除，旧筛选不影响目录内容。
- 目录搜索以当前目录为边界，包括下级目录及文件，不返回同级分支或上级文件。
- 资料库与经验沉淀均使用列表。目录标签用于展示，不产生无法清除的隐藏过滤。
- 创建者、管理员可在项目及各级目录新增、上传；其他可读成员看到禁用入口和原因。已发布经验共享，草稿与管理权限保持独立。
- 多项目、多目录、多文件的提问范围取递归并集，去重并重新验证权限；空范围、跨库范围不能退回全库。
- 问答返回恢复目录、页码及勾选；账号之间不共享会话和来源位置。
- 上传默认保存到当前位置，重复内容明确拒绝；阅读原件、收藏、回收站恢复必须与列表状态一致。

## 页面检查

24 项实际操作断言通过，覆盖：总览、三级目录、筛选精简、目录搜索边界、目录名称搜索、分类切换、只读入口、管理员入口、多项目 26 份资料、多目录 22 份资料、实际会话保存、来源返回、第 2 页勾选恢复、收藏及取消、空项目创建、连续创建目录、实际上传、重复上传、TXT 归档原件阅读、共享经验、统一列表、回收站恢复、账号切换和标签状态。

页面检查使用可见角色、名称和状态断言；弹窗关闭等待隐藏状态，不以固定延迟代替完成判断。可重复执行的核心流程在 `scripts/manual/knowledge_business_flows.mjs`，由 cua_repl 传入已绑定的 tab 执行。

## 接口检查

- 22 个接口操作，正向及反向数据生成共 505 次请求；6 组在固定必要标识后没有可生成的非法参数，标为不适用，不计入通过。
- 检查服务器错误、已有响应 schema、内容类型；权限、空范围、跨库、账号归属使用显式业务断言。
- 206 次专项及状态机调用，覆盖创建项目、嵌套目录、上传、目录与选择范围一致、删除、恢复、重复恢复拒绝。
- 只读成员直接调用创建或上传被拒绝；未登录和停用账号被拒绝；他人会话编号不能绕过账号归属。

可重复执行：

```powershell
python -m pip install -r test/requirements-knowledge-audit.txt
python scripts/manual/knowledge_audit_app.py --data-dir <空的验收目录> --port 8896
python scripts/manual/check_knowledge_contracts.py --url http://127.0.0.1:8896 --output <结果文件.json>
```

验收程序只能绑定回环地址，拒绝未标识的非空数据目录，并阻断外部服务连接。不得把验收 app 挂到正式服务。

## 修复

1. 子目录搜索原来扩大到整个项目，现限制为当前分支，并可查找下级目录名称。
2. 文件标签原来能在目录内触发无清除入口的筛选，现改为静态标签。
3. 经验沉淀仍有独立卡片分支，现与资料库共用列表，保留笔记编辑入口。
4. 全库问答原来仍显示“向所选资料提问”，现按全部资料、选中文件或个人范围显示标题。
5. 422 错误原来只声明 FastAPI 的错误列表，但业务校验返回文字；现公开两种实际返回结构，补充回归测试。

同时校正只读权限提示与阅读片段提示：拥有阅读权限不代表全员公开；片段数量不代表原文件页数。

## 结果边界

本轮验证业务操作与状态一致性，浏览器使用当前连接的 Chromium。云端检索质量、真实模型回答质量、生产登录流程、Office 转换兼容性及大文件性能不由这组隔离测试证明。现有后端回归另行覆盖原件权限、版本和笔记发布等路径。
