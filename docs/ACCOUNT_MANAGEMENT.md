# 邀请注册与公司账号管理

当前按单公司部署设计，同一部署的管理员可以管理普通账号和其他管理员。普通账号只能访问自己的研究项目，公司知识库须另行授权。

## 管理员使用

管理员登录后，侧边栏进入“账号管理”：

- “账号列表”：搜索、分页、按账号类型和状态筛选，启用或停用账号，重置密码，提升或降级角色。普通账号的公司知识库权限可单独设置；管理员按角色拥有权限。角色变更后旧登录凭证失效；停用账号须先启用再提升。
- “编辑资料”：管理员可为普通账号或管理员填写姓名（最多100字）、备注（最多1000字），两项均选填，可清空。账号列表支持按用户名、姓名或备注搜索。姓名、备注仅供管理员查看和管理，登录用户名保持不变；当前不包含部门字段。
- “操作日志”：按操作人、操作对象的用户名或当前姓名、操作类型和日期范围查询，支持分页。展示时间、人员、对象和变更摘要，涵盖现有账号/邀请/密码操作以及新增的资料编辑；只读展示历史记录。系统过期清理单独标记，创建人列为关联人员。
- 至少保留一个启用的管理员；服务端对并发停用、降级操作串行检查，停用的管理员不计入可用数量。操作自己的角色或状态后立即退出，自己的密码使用侧边栏“修改密码”修改。
- “邀请管理”：选择普通账号或管理员类型，设置1至168小时有效期（默认6小时），生成随机邀请码，查看使用情况或撤销未使用邀请。
- 已撤销、已使用的邀请可点击“删除”，确认后从邀请表移除；有效邀请须先撤销。创建、使用、撤销日志保留，另记录删除人、时间、邀请编号及原状态，不保留邀请码或摘要。删除邀请不影响已注册账号，其邀请来源仍可从日志追溯。
- 不用的账号先“停用”，再“归档账号”。归档账号默认隐藏，可在状态筛选“已归档”中查找并恢复；用户名仍保留，不可重复注册，任务、报告、聊天及历史资料均保留。恢复后仍保持停用，须单独启用；旧登录凭证不会恢复有效。归档期间只提供恢复操作，不能直接修改资料、角色、知识库权限或重置密码，当前登录账号和最后一个启用的管理员受保护。归档与恢复均记录操作日志。
- 邀请码只展示随机代码，不包含网址，关闭前须复制保存。丢失后请撤销旧邀请并重新生成。
- 每条邀请只能成功注册一个对应类型的账号，打开或校验邀请不会消耗它。注册失败不消耗邀请。注册角色由服务器保存的邀请类型决定，客户端不能自行指定角色。
- 到期邀请自动从列表及有效邀请表清理，后台每分钟执行一次；打开或刷新邀请列表也会触发清理，页面每30秒自动刷新。审计日志保留创建人、使用账号、时间与邀请编号，不保存邀请令牌或摘要；普通账号的邀请来源会保留。
- 重置密码后临时密码仅展示一次。旧密码及旧登录凭证立即失效，用户须用临时密码登录并修改后才能使用业务功能。
- 停用保留历史资料，后续受保护请求将被拒绝；启用后须重新登录。不会停止已在后台执行的研究任务或追溯撤回已传输数据。

新用户进入网站，从“普通用户 → 邀请注册”粘贴邀请码，填写用户名、密码及确认密码。管理员邀请码可从管理员入口注册，校验后按邀请角色显示注册页面。以前生成的完整邀请链接仍兼容。密码为8至128位，须包含字母和数字，首尾不得有空白。邀请到期不影响已注册账号。

新管理员通过管理员专属邀请码设置用户名和密码，注册后即可登录。也可以通过 `scripts/create-admin.py` 引导创建初始管理员。所有在线注册均须提供有效邀请，注册请求不接受角色或旧固定管理员注册码。

## 密码验证与登录限流

重置其他账号密码、提升或降级角色、启停管理员、生成管理员邀请码，均须再次输入当前管理员密码。验证凭证有效期5分钟，绑定操作、目标账号、操作人和登录凭证版本；成功操作后不能重复使用。普通邀请码生成及普通账号的启停、知识库授权不需额外验证。

同一用户名5分钟内累计输错5次登录密码后暂时限制登录，窗口结束恢复；登录成功清零失败次数。同一来源每分钟最多60次登录或管理员身份验证请求。管理员身份验证、修改密码时输入原密码也有独立的5次/5分钟失败限制。超限返回429及 `Retry-After` 秒数。限流记录保存在数据库中，重启或多进程不会清零；不直接记录用户名、IP或密码。过期验证凭证和一天前的限流记录由后台清理。

## 数据迁移与部署

部署前备份数据库。新版本启动时自动执行版本化迁移（当前为 `20261020_account_archives_v5`）；也可在停止旧服务后单独运行：

```powershell
# 只检查，不修改
.\.venv\Scripts\python.exe scripts/migrate-accounts.py
# 执行增量迁移，不加载模型或研究工作流
.\.venv\Scripts\python.exe scripts/migrate-accounts.py --apply
```

迁移新增用户状态、凭证版本、临时密码标记、知识库授权、最近登录时间，以及邀请、操作日志和版本记录表。保留已有账号、密码哈希、项目及聊天；已有账号默认启用，旧JWT按凭证版本0兼容，直至到期或账号被停用、密码被更改。

管理员邀请升级为邀请记录增加角色字段，已有邀请全部保持普通账号类型。安全升级新增账号管理互斥行、一次性操作确认和限流表，保留现有账号、邀请及审计记录。每次迁移独立记账，不会重新导入已迁移的知识库授权。

资料与日志升级仅新增姓名、备注字段（已有账号默认为空），以及日志时间与类型索引。日志接口按白名单生成变更摘要，不返回原始日志 JSON、密码、密码摘要或邀请码；资料编辑日志记录变更字段，不复制备注正文。编辑资料不会改变密码、角色、凭证版本或研究资料，也不要求用户重新登录。

归档升级仅新增可空的 `users.archived_at` 字段，原有账号均保持未归档。`GET /admin/users` 默认排除归档账号，`state=archived` 单独查询；归档、恢复分别使用 `POST /admin/users/{id}/archive`、`POST /admin/users/{id}/restore`，已撤销或使用的邀请使用 `DELETE /admin/invitations/{id}`。这些操作均要求管理员身份，账号变更与审计、邀请删除与审计在同一事务内提交。

日志日期按浏览器本地日期选择，起止日期均包含在内；接口接收带时区的 `start` / `end`，使用起始时刻包含、结束时刻不包含的范围。历史上未记录的事件不会补造，日志中的姓名使用账号当前资料。

`COMPANY_KNOWLEDGE_USERS` 仅在首次迁移时导入已有账号的知识库授权。之后以数据库为准，改动环境变量或重启不会覆盖管理员在页面中的授权或撤权。新注册普通账号默认不开放公司知识库，管理员按其角色拥有管理员访问权限。

邀请采用随机令牌，数据库仅存SHA-256摘要。页面展示及复制纯邀请码；旧链接的 `/#invite=...` 和查询参数格式仍可读取，前端读取后清除地址栏令牌。邀请码、临时密码及操作确认凭证不写入操作日志。操作日志保存在 `account_audits`，记录操作人、对象、时间及变更项。

先迁移并更新后端，再同步更新前端文件，避免新旧注册参数不兼容。反向切换到旧版会恢复旧注册及鉴权逻辑，因此不能用旧服务作为保留新权限规则的回滚方案。

## 本地隔离验证

```powershell
$env:PYTHONPATH = (Resolve-Path backend).Path
.\.venv\Scripts\python.exe -m pytest test/test_accounts.py test/test_company_knowledge.py test/test_company_workspace.py -q
node test/frontend_accounts.cjs
node test/frontend_industry_params.cjs
# 本地账号管理联调：真实前端 + 临时数据库，跳过邀请流程
.\.venv\Scripts\python.exe scripts/check-accounts-ui.py --local-management-only
# 完整隔离浏览器回归可另行运行 scripts/check-accounts-ui.py
# 可选：在临时 PostgreSQL schema 内验证同一组账号测试
$env:ACCOUNT_TEST_POSTGRES = '1'
.\.venv\Scripts\python.exe -c 'from dotenv import load_dotenv; load_dotenv(); import pytest; raise SystemExit(pytest.main(["test/test_accounts.py", "-q", "-k", "postgresql"]))'
```

测试使用临时数据库；覆盖并发邀请消耗、失败回滚、过期和撤销、管理员越权、账号状态、知识库授权、密码重置和强制修改、旧JWT兼容及迁移幂等性，以及并发保留最后一个管理员、确认凭证过期/重放/跨操作拒绝和数据库限流。上线后的外部邀请访问验收单独进行。

默认 pytest 配置禁止外部请求和真实向量模型，并隔离本机 `.env` 与业务文件。上述 PostgreSQL 命令在 pytest 前显式读取连接配置，测试仅在独立 schema 中创建、使用及清理数据；若连接远程测试库，需额外传入 `--allow-network`。

归档与邀请删除验证包含关联资料保留、恢复后仍停用、归档期间变更拒绝、并发归档/启用、重复删除、邀请来源与旧日志保留、操作取消及删除后分页回退。`--local-management-only` 用预置的邀请状态验证删除，不执行邀请注册流程。
