## 个人首页

登录后查看当前账号自己的任务概况、最近任务和最近报告；管理员的个人首页也只统计自己的项目。可进入任务、下载成果、查看历史版本。

<a id="getting-started"></a>

### 新人入门与完整工作流程

建议按这个顺序开始：
1. 登录后在“个人首页”看自己的任务和最近报告。
2. “提交尽调任务”选择公司、人物或行业报告，填写研究对象、范围和重点问题，可上传已有资料。
3. 在“任务管理”展开任务，查看工作流和成果，下载第一阶段报告，并核对质量说明、来源和待复核事项。
4. “复核与一手资料”中由任务创建人本人进行日常复核，上传修订稿、访谈或走访资料，再点“二阶段再生成”。管理员也有项目管理权限，但生成完成不代表已经完成本人复核。
5. “溯源库”核对来源记录，必要时到原网站查原文。
6. 报告完成公司知识库入库和索引后，在“公司知识库 → 我的项目”阅读、提问和总结。小助手负责解释系统用法，内部项目事实交给知识库问答。

也可以这样问：“新人入门”、“新手入门”、“新人怎么开始”、“我是新人”。

<a id="login"></a>

### 角色入口、邀请注册与登录

路径：登录页 → 先选“普通用户”或“管理员” → “登录”或“邀请注册”。注册时粘贴管理员提供的有效邀请码，也支持完整邀请链接，再填写自选用户名、密码和确认密码。邀请码绑定注册角色，不能靠自己选择入口提升权限；正常账号注册后即可使用公司知识库；普通账号仅可读取内部资料。密码为8至128位，须含字母和数字，首尾不能有空白。邀请码过期、被撤销或已使用时，请联系管理员重新提供；不能重复注册多个账号。登录提示角色不符时返回“重新选择”，改用与账号实际角色对应的入口。

也可以这样问：“如何注册”、“怎么注册”、“邀请注册”、“邀请码”。

<a id="password"></a>

### 修改密码与临时密码

路径：页面右上角当前登录账号区域 → “修改密码”。填写当前密码、新密码和确认新密码；新密码为8至128位，须包含字母和数字，首尾不能有空白。管理员重置后获得的是临时密码，首次使用必须在“请修改临时密码”页面设置自己的新密码后才能进入业务功能。改密会使旧登录凭证失效，其他浏览器需重新登录。请在密码表单里输入密码，不要发给小助手。

也可以这样问：“修改密码”、“更改密码”、“临时密码”、“强制改密”。

<a id="login-problems"></a>

### 忘记密码、账号停用与登录过期

忘记当前密码时，请联系管理员在账号管理中重置，拿到临时密码后登录并修改。账号停用或归档也需要联系管理员处理，重新注册不能恢复原账号历史。提示“登录已过期”时重新登录；修改密码、重置密码、调整角色或停用账号都可能使旧凭证失效。频繁登录或管理员验证可能触发短时间限流，请按提示稍后再试。小助手不能读取密码、解锁账号或替你重置密码。

也可以这样问：“忘记密码”、“忘了密码”、“重置密码”、“登录不了”。

<a id="home-overview"></a>

### 个人首页的概况与最近成果

个人首页展示当前账号自己的任务总数、执行中、已完成和待继续/待处理概况；管理员的个人首页也只统计本人项目。“最近任务”最多展示最近更新的6个项目，“最近报告”最多展示6条最新成果，报告和建议书按各自最新记录归集，不代表全部历史。进入对应任务查看完整成果；也可直接下载最近报告、打开历史版本或进入复核。刷新概况只重新获取状态，不会重跑任务。管理员在任务管理可见的项目范围比个人首页更广，两个页面数量不同不一定是丢数据。

也可以这样问：“个人首页”、“首页概况”、“最近任务”、“最近报告”。

<a id="assistant-role"></a>

### 小助手、知识库问答与执行权限

小助手的主要职责是系统使用指南：解释功能入口、填写方式、权限、处理状态和故障排查；也支持闲聊、写作及按需查询天气/公开网页。它不读取你的项目报告、公司知识库正文、真实任务状态或管理日志，内部事实问题应到公司知识库或对应页面核对。它不能替你提交任务、删除资料、修改账号或审批权限；操作需由你在相应界面确认执行。
在知识库界面，小助手可以读取经过权限核验的当前项目/子目录名称及笔记归档位置，用于解释保存位置；不读取正文、图片内容、项目说明或私有草稿文本。

也可以这样问：“小助手是干什么的”、“小助手能做什么”、“系统使用指南”、“小助手和知识库”。

<a id="assistant-use"></a>

### 全站小助手、输入换行与移动端

登录后各业务页面都可打开同一个小助手，切换页面会保留当前对话，并更新“当前页面帮助”。桌面可拖动窗口/入口；手机和较小窗口会适配屏幕。Enter发送，Shift+Enter换行，中文输入法选字时不会直接发送；Esc或关闭按钮可收起。向上阅读旧消息时不强制跳到底部，点“回到最新消息”恢复跟随。相关页面入口只用于导航，不会代你执行业务操作。
入口固定浮在页面上层，知识库、经验沉淀、笔记/上传弹窗中都可打开；拖动入口会记住位置。先关闭助手可继续操作背后的弹窗，不会关闭或丢弃笔记。

也可以这样问：“打开小助手”、“关闭小助手”、“小助手拖动”、“Shift+Enter”。

<a id="assistant-memory"></a>

### 账号记忆、AI摘要与重新登录恢复

小助手对话和引用按账号保存在服务端；同一账号连接同一套后端数据库，重新登录或换浏览器/电脑可以恢复。需要模型续聊时，当前会话的“摘要 + 未摘要消息”超过约12000字符或未摘要消息超过40条时，尝试用当前模型提炼旧对话，保留近期上下文，原始消息不因摘要而删除。摘要最多3000字符，可能遗漏细节，失败会提示仅参考部分历史并在后续重试。页面先加载最近80条消息，可“加载更早消息”；退出登录清空当前页面并中止请求，不删除服务端历史。

也可以这样问：“小助手记忆”、“压缩对话”、“多少轮”、“记住聊天”。

<a id="assistant-conversations"></a>

### 新对话、重新加载与清空记录

小助手顶部“新对话”创建空上下文，旧会话仍保留，可通过下拉框切换（列出最近创建的100个会话）；新会话不会自动带入另一个会话的记忆。“重新加载”从服务器核对当前账号保存状态，网络中断后可用它确认结果。“加载更早消息”分页读取较早记录。“清空记录”会要求确认，删除当前账号全部小助手对话、引用和摘要并开始空会话，不能撤销，不影响公司知识库。当前没有按天自动过期；清除浏览器缓存也不等于删除服务端聊天。

也可以这样问：“新对话”、“清空记录”、“清空小助手”、“删除聊天”。

<a id="assistant-online"></a>

### 天气、公开搜索与信息时效

小助手沿用部署时配置的聊天模型，具体型号以当前服务配置为准，不能保证每个环境都相同。天气需明确城市，没说城市会先问，可查询服务提供的当前天气及最多三天预报；看清观测时间，缺日期/时区时会明确说明。公开网页搜索按需使用一家已配置服务，回答附来源和查询时间；摘要不等于读完整网页。普通聊天和系统操作说明不需要联网，系统指引以本地维护的功能说明为准，不能用网上别的产品教程替代。失败时不能编造实时事实，结果不会自动进入公司知识库。

也可以这样问：“小助手联网”、“联网能力”、“能查天气吗”、“怎么查天气”。

<a id="troubleshooting"></a>

### 问题反馈与系统不支持的操作

先核对当前账号和角色、所在页面、筛选条件以及处理状态，再记录具体错误、任务名称/ID、报告记录编号或资料名称，必要时附截图交管理员/维护人员排查，不要发送密码或密钥。小助手只能依据已维护的实际功能说明回答；没有对应入口或规则时会说明尚未确认并询问具体页面，不编造按钮。当前不能让小助手代操作、自动审批或设置定时任务；历史版本没有差异对比/一键恢复，任务删除没有批量入口。

也可以这样问：“功能没有反应”、“报错怎么办”、“怎么反馈问题”、“没有这个功能”。

<a id="assistant-privacy"></a>

### 谁能看到小助手聊天记录

小助手聊天记录按登录账号ID隔离，会话读取、切换、续聊和清空都检查所属账号；普通用户与业务管理员都不能通过小助手接口读取其他账号的会话。退出登录会清空当前页面，下一账号不会继承对话。它不是端到端加密产品，数据库运维的访问能力与业务管理员界面权限是不同层面；不要在聊天中发送密码、密钥或令牌。旧浏览器历史只在首次迁移时导入当前账号，已有云端记录不会被另一份旧缓存覆盖，清空后旧缓存也不能自动恢复已删消息。

也可以这样问：“管理员看聊天”、“聊天隐私”、“别人看聊天”、“聊天记录权限”。

<a id="assistant-images"></a>

### 小助手看图聊天、截图指引与图片保存

打开小助手，在输入框上方点“＋ 添加截图”，或在输入框中粘贴剪贴板图片；可先看缩略图，点图片右上角“×”删除。每次最多2张，单张不超过3 MB，支持静态PNG、JPEG、WebP。可以问“这是一个人吗”“图里有什么”等普通图片问题，也可以问系统的页面、按钮或报错。只发图时会尝试描述图片。普通看图聊天直接回答，系统操作求助才核对本地指南；不能仅因图片含有聊天框或按钮就强制按操作求助处理。模糊或问题不明确时会要求补充，不猜按钮、不自动操作。小助手统一使用阿里视觉语言模型处理文字和截图。原图只用于本轮识别，不进入知识库或溯源库，也不保存到服务端历史；刷新或重新加载后需重新发送。聊天记录仅保留附图数量、识别成功时的短文字观察和回答，观察可能不准确，不代表后台真实状态。

也可以这样问：“发送截图”、“上传截图”、“粘贴截图”、“发图片”。

<a id="tasks"></a>

## 任务管理

按关键词、状态和研究类型组合筛选任务，展开查看成果、实时工作流、项目参数和来源；支持暂停、继续、重跑、下载、历史版本和逐条删除。

<a id="task-filters"></a>

### 任务搜索、状态类型筛选与分页

路径：任务管理（复核与一手资料也有相同筛选）。搜索项目名称、研究对象、行业或状态，再组合“全部状态”和“全部研究类型”筛选；各条件同时生效，点“清空筛选”恢复。状态区分未开始、执行中各阶段、已暂停、已完成、执行失败和待检查等。筛选后页码会回到前面，可在底部调整每页数量并翻页；表格较宽时左右滑动看固定操作栏。找不到项目时先清空筛选、确认登录账号和可见范围，再核对项目是否删除。复核项目被筛选隐藏后会清除复核选择和待上传文件，避免误操作。

也可以这样问：“任务筛选”、“筛选任务”、“搜索任务”、“全部状态”。

<a id="task-detail"></a>

### 展开任务查看项目参数和工作流

在任务管理点行首展开箭头或“查看”。详情集中展示最新成果、工作流进度、项目参数及已有来源；“全部产物”可按时间查看更早的成果和中间产物。项目参数可核对研究对象、报告类型、周期、所属行业、身份线索和上传资料。进行中的任务会自动刷新进度，展开后可查看具体步骤。进度条是阶段估计，不代表每个事实已核验，也不能单凭百分比保证完成时间。

也可以这样问：“查看任务”、“任务详情”、“展开任务”、“项目参数”。

<a id="pause-resume"></a>

### 暂停、继续与重跑任务

路径：任务管理 → 对应任务操作栏。执行中的任务可点“暂停”；这是暂停请求，当前外部请求完成后会在安全检查点暂停，显示“正在暂停”时请等待。已暂停或失败的任务可点“继续”，已完成任务可点“重跑”；会读取项目已有运行参数，不是把提交页当前表单套到旧项目。重跑可能生成新的成果记录，请在历史版本中核对。后台已在运行时无需重复启动，先展开任务查看实时进度。

也可以这样问：“暂停任务”、“任务暂停”、“继续任务”、“恢复任务”。

<a id="refresh-heartbeat"></a>

### 刷新页面、心跳与任务看起来卡住

研究任务在后端线程执行，刷新或关闭页面通常不会终止已启动的工作流；重新打开任务详情可继续看持久化进度。查看最后心跳、当前步骤耗时和外部服务提示；“可能卡住”是心跳过久提示，不等于已确定失败。不要连续点重跑。需要暂停时用任务操作栏“暂停”；服务进程重启会中断进程内任务，过期活跃状态可能被恢复为“已暂停”，再通过“继续”恢复。

也可以这样问：“刷新页面会停止吗”、“关闭页面”、“页面刷新”、“任务卡住”。

<a id="download-reports"></a>

### 下载报告、建议书和中间成果

路径：任务管理 → 展开任务 → “最新成果”，选择具体产物点击下载；行操作栏的“下载”是快速入口，个人首页最近报告也能下载。更早的产物请打开“全部产物”，报告正文的历次记录也可从“报告历史版本”查看。没有可下载成果时按钮会禁用，请先看工作流状态或展开查原因。桌面研究报告回答研究问题，项目建议书描述后续项目安排与建议；质量诊断、清洗事实等属于辅助产物。文件导出格式以实际可用文件为准，Word导出失败时不能承诺一定可下载Word，先查看错误和可用正文/原件。

也可以这样问：“下载报告”、“报告下载”、“成果下载”、“下载建议书”。

<a id="report-history"></a>

### 历史版本、记录编号与正文预览

路径：任务管理展开任务 → “历史版本”，或个人首页最近报告 → 历史版本。弹窗可切换“研究报告”和“项目建议书”，按保存顺序显示“记录 001”等编号，最新记录在前；每条保留当时内容、时间、生成方式和复核提示。点“查看”预览正文，点“下载”获取该条文件；超过一页时翻页。长正文预览仅显示前12万字，完整内容下载核对。人工修订“覆盖”会创建新的版本，不是删除所有旧稿；目前没有左右版本差异对比或一键恢复旧版的按钮。

也可以这样问：“历史版本”、“报告版本”、“旧报告”、“以前的报告”。

<a id="quality-warnings"></a>

### 待复核稿、事实摘录和核验问题

报告显示“待复核稿”时，展开成果并点击复核原因、核验问题或“部分章节使用事实摘录”，核对证据缺口、主体匹配、数字口径和引用。“建议书待确认”也需按提示处理，不能把完成状态当作正式交付验收通过。事实摘录表示部分综合写作降级，不代表内容已经自动人工审核。建议下载报告质量诊断和原始来源，对照引用复核，再在复核与一手资料上传修订稿或补证。

也可以这样问：“待复核稿”、“质量说明”、“质量诊断”、“事实摘录”。

<a id="word-export"></a>

### Word导出、文件检查与版式校验

在成果区分别检查“Word 导出失败”“Word 文件检查通过”和“版式未校验”等提示。文件结构检查通过不等于逐页版式或事实质量验收通过；版式未校验表示没有完成对应渲染检查。历史版本可先预览正文，下载可用原件核对。文件打不开或乱码时保留任务、记录编号和错误提示反馈管理员/维护人员，不要把坏文件直接交付；当前没有对所有报告通用的一键重新导出按钮。

也可以这样问：“Word导出失败”、“导出异常”、“版式未校验”、“Word文件检查通过”。

<a id="report-archive"></a>

### 第一阶段报告自动归档与重试

第一阶段桌面研究报告生成后，会尝试自动加入创建人的公司知识库项目，默认待复核且限制访问（创建人和管理员可读），不是自动向全公司公开；报告生成状态与入库/索引状态是两条流程。路径：任务管理 → 展开 → 对应桌面研究报告下方“公司知识库”状态；未归档或失败时点“重试归档”，或“前往我的项目”查看。只有入库并完成索引后才能用于知识库RAG问答。入库失败不代表报告丢失，仍可下载；普通账号仅能在知识库访问内部等级的报告，机密报告由管理员管理；服务配置异常时联系管理员。

也可以这样问：“自动归档”、“重试归档”、“入库失败”、“报告没进知识库”。

<a id="facts-index"></a>

### 行业清洗事实的单独索引重试

任务详情中若行业“清洗事实”产物显示索引异常，可使用该产物旁的索引重试入口；它只重建行业清洗事实索引，不重跑整份报告，也不等同于公司知识库报告归档。只适用于行业清洗事实产物，不能把它当作所有成果通用的修复按钮。公司知识库文件处理失败应在资料库中点该文件的“重试”；桌面研究报告归档失败使用“重试归档”。

也可以这样问：“重试索引”、“事实索引”、“重建索引”、“清洗事实索引失败”。

<a id="delete-task"></a>

### 删除任务与单个成果

路径：任务管理 → 对应任务“删除”，页面确认后会删除研究项目及关联来源、产物和项目存储文件，属于不可随意撤销的操作；运行中的任务不能删除，先暂停并等待后台结束。展开后也可删除单个成果，删除成果与删除整个任务不同。界面按任务逐条操作，没有批量删除任务或回收站入口。公司知识库的独立归档副本需在知识库中另行核对、管理，不能承诺删除研究任务就自动清除了所有其他位置的副本。

也可以这样问：“删除任务”、“删除项目”、“删除成果”、“批量删除任务”。

<a id="project-permissions"></a>

### 任务可见范围与管理员权限

普通用户只能访问自己的研究项目；管理员可访问其他用户项目。个人首页对两种角色都只展示本人项目，因此首页与管理员任务列表可能数量不同。复核与一手资料也受项目访问权限控制，日常流程仍由创建人本人核对报告。公司知识库普通账号默认可用，资料另按保密等级及文件授权控制，小助手聊天历史则始终只属于当前账号，管理员不能通过小助手接口读取别人的会话。

也可以这样问：“谁能看任务”、“别人的任务”、“管理员看所有项目”、“任务权限”。

## 复核与一手资料

日常由任务创建人本人复核；管理员也有项目管理权限。选择项目，上传人工修订报告或建议书、补充访谈走访资料，再执行二阶段再生成。

<a id="review-select"></a>

### 选择复核项目与上传修订稿

路径：复核与一手资料 → 搜索/筛选项目 → 点击该行“复核”，确认展开区顶部“当前复核项目”。日常由任务创建人本人检查事实、引用、质量缺口和判断；管理员也有项目管理权限。分别选择人工修订的Word/PDF/Markdown文件，点“覆盖桌面研究报告”或“覆盖项目建议书”。系统会保存为最新成果版本，保留旧记录供历史版本查看，并作为后续二阶段的资料。仅选中本地文件但未点覆盖，不代表已提交。

也可以这样问：“怎么复核”、“如何复核”、“人工复核”、“人工修订”。

<a id="field-materials"></a>

### 专家访谈、走访和一手资料入库

路径：复核与一手资料 → 选择项目并点击“复核” → 专家访谈/走访一手资料。选择专家访谈、实地走访、客户访谈、供应商访谈、渠道访谈或管理层访谈，添加笔录、转写文字、照片或书面材料，再点“上传并入库”。图片会进入OCR/视觉处理流程，文本会尝试解析/索引；最终以处理状态和来源记录为准。建议录音先转成可阅读文字，当前页面没有录音按钮或保证自动语音转写完成的专用入口。

也可以这样问：“专家访谈”、“一手资料”、“走访”、“访谈资料”。

<a id="second-stage"></a>

### 二阶段再生成与第一阶段的区别

第一阶段主要做桌面研究；二阶段优先使用人工复核产物和专家访谈、走访等已有一手资料。路径：复核与一手资料 → 点“复核”选择项目 → 上传并提交修订稿/补充资料 → 右上角“二阶段再生成”。未选择项目时按钮不可用。二阶段会关闭公开在线搜索，重新清洗和生成报告、建议书，结果回到任务管理和历史版本核对；专业平台/OCR等仍依独立策略和配置，不能承诺完全没有任何网络请求。上传成功、再生成完成与人工复核通过是不同状态；材料不充分时仍需补证，不会因为点了按钮就自动完成审查。

也可以这样问：“二阶段”、“二阶段再生成”、“第二阶段”、“二次生成”。

### 查询溯源记录与跳转原站

### 网页正文保留、失效链接与溯源库问答边界

也可以这样问：“网页正文”、“爬取正文”、“溯源库RAG”、“溯源库问答”。

<a id="company-knowledge"></a>

## 公司知识库

研究首页、资料库、研究问答和经验沉淀组成公司知识库。资料库保存研究原件与成果；经验沉淀保存照片、手稿、录音、视频与图文笔记，两者不跨库检索。根目录可直接上传独立文件，也可创建项目后进入目录上传或记录。小助手解释用法，研究问答检索有权限的已索引正文。

<a id="knowledge-access"></a>

### 知识库资格、文件授权与锁定资料

正常账号注册后即可使用公司知识库，已有普通账号也无需单独开通。普通账号仅可访问内部资料；机密资料仅管理员可用，旧创建人身份、指定成员和审批都不能突破等级限制。内部资料默认共享，单独授权的内部资料仍按创建人、管理员及指定成员控制，其他成员可申请访问。阅读、预览、下载、搜索、问答及历史引用统一校验权限。普通账号可管理自己的内部项目和文件，不能创建或改为机密；停用、归档账号不能使用。小助手不能越权解锁。所有启用管理员共享审批列表，任一管理员处理后结果同步；页面定时更新待审批数量，不发送邮件或短信。
经验沉淀采用全员共享阅读策略，历史经验的单独授权也不再限制正常成员阅读；管理、删除仍由创建者或管理员执行，未发布草稿保持私有。资料库继续保留原有等级和授权限制。

也可以这样问：“知识库打不开”、“知识库使用资格”、“知识库无权限”、“没有知识库权限”。

<a id="knowledge-home"></a>

### 知识库研究首页与资料归集

进入公司知识库，可切换“知识库首页”“资料库”“智能问答”和“经验沉淀”。首页提供搜索资料、最近更新、最近浏览和常用项目。点击项目进入归档目录；资料库与经验沉淀分别检索，不跨库混搜。收藏和阅读历史保存在当前浏览器，研究会话保存在服务器。

也可以这样问：“研究首页”、“知识库首页”、“项目资料”、“最新资料”。

### 我的项目与AI总结我的项目

路径：公司知识库 → 资料库 → 我的项目。按当前登录账号ID归集本人上传资料及本人任务自动归档的报告，按所属项目统计，不是按姓名文本猜归属，也不是自动显示所有能阅读的公司项目。“我的项目”进入本人范围；“AI 总结项目”仅基于本人可用资料发起有引用的总结，未完成索引或没有资料时无法形成有效总结。项目归集为空时检查账号、资料所属项目、归档和索引状态。

也可以这样问：“我的项目”、“AI总结我的项目”、“总结本人项目”、“我的项目数量”。

<a id="knowledge-upload"></a>

### 知识库批量上传、格式与32MB限制

路径：公司知识库 → 资料库或经验沉淀 → “上传文件”。根目录可直接上传独立文件，或选择项目及子目录；项目中上传默认选中当前目录。选择项目时，文件继承项目行业、分类、标签、复核标记及权限。
可多选PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX、TXT、MD、JPG/JPEG、PNG，单个不超过32 MB；MP3/WAV/M4A/OGG/FLAC/MP4/WEBM单个不超过128 MB。文档与图片解析并建立索引；音视频原件可播放、下载，填写的文字说明参与检索，不自动转写。
普通账号可上传根目录独立文件；项目内上传须为项目创建者，管理员可管理；同目录同名不同内容保留新版本，相同内容提示重复。上传成功后仍要等待解析和索引，不代表立即可问答；单项失败优先重试该项。
根目录“上传文件”与“创建项目”并列，项目和独立文件同级展示并分别计数。上传位置可选根目录、可管理的项目及子目录；根目录新文件默认内部且所有正常账号共享，上传后可在文件设置调整。文件“移动”会连同同名历史版本整理，确认框显示前后权限：移入项目继承目标项目分类、标签及权限，管理权跟随目标项目归属人；移回根目录保留原权限和归属人，不自动改成共享。同名目标不会被覆盖，处理中的文件需完成后移动，图文笔记与自动研究成果在所属项目管理，资料库和经验沉淀不能互相移动。

也可以这样问：“知识库上传”、“上传资料格式”、“32MB”、“32 MB”。

<a id="knowledge-processing"></a>

### 文件处理状态、重试与不能勾选

文档和图片经历等待处理、上传、解析/OCR、建立索引，完成后显示“可检索”或“正文可检索”。只有你有阅读权限且状态为可检索的文件正文才能勾选为问答依据；失败时查看状态说明，管理者重试原记录。音视频原件按归档与文字说明处理，不自动把录音或视频内容转成文字。图文笔记未发布的草稿不参与RAG，发布后还要等索引成功。重复上传不能代替失败处理；先核对权限、格式、大小和错误信息。

也可以这样问：“文件不能勾选”、“资料不能勾选”、“不能选择文件”、“等待处理”。

<a id="knowledge-filters"></a>

### 知识库筛选、排序、分页和保存视图

路径：公司知识库 → 资料库或经验沉淀。目录搜索按文件名、项目及已有说明定位；行业、复核状态和左侧分类可以组合使用，“更多筛选”仅保留上传/更新时间范围。处理失败从左侧“处理失败”查看，文件状态仍在列表显示。可切换最近更新/名称排序，文件每页10、20或50条。条件会叠加，找不到文件先清空筛选，再检查当前库、目录、本人/收藏范围与权限。目录与资料并行加载，进入目录不再等待装饰动画。 筛选、排序和分页视图按账号保存在当前浏览器，换浏览器不会自动同步。

也可以这样问：“筛选资料”、“资料库筛选”、“筛选项目”、“筛选行业”。

<a id="knowledge-reading"></a>

### 原件阅读、PDF翻页与下载

点击阅读入口或双击文件卡片打开原件。PDF 与 Word、Excel、PowerPoint 通过服务端分页预览连续阅读，首屏加载后按需展开后续页；第一次转换可能需要数秒，再次阅读复用版式缓存，每次仍检查权限并添加个人水印。图片直接预览，文字按原文编码显示，音视频可播放。预览失败会明确提示，不能据此认定原件删除；可重试或下载水印副本。
解析片段是可检索文字，可能合并多页、存在重叠，或缺少图片和识别失败的内容，不等同于原件全文。切到“解析片段”可继续加载后续页并查看已加载数量。阅读框“搜索解析文字”会检查全部可用片段、跳转命中片段并高亮；扫描件查OCR文字，已知原文页码时可“查看对应原文页”。音视频只搜索手工说明，不自动转写。正式引用仍需对照原件。
大XLSX自动使用表格数据预览：可切换工作表，每页50行，并按行页码跳转；宽表可分列查看。公式显示原式，不重新计算；图片、图表和打印版式以原件为准。需要打开密码的PDF会明确提示已加密，应上传已解除打开密码的版本；损坏PDF另行提示格式异常。
缺少归档原件的历史资料明确显示原件缺失，仍可阅读现有解析文字。管理者可点击“补传原件”，核对对应文件并确认后保留原位置、权限及资料编号，按补传内容重新建立索引，旧解析依据立即停用；其他成员请联系管理者。

也可以这样问：“阅读原件”、“下载原件”、“PDF翻页”、“原件预览”。

<a id="knowledge-favorites"></a>

### 收藏、继续阅读与本地浏览记录

资料库可对可访问文件收藏，再从“我的收藏”集中查看；研究首页“继续阅读”展示最近打开的文件。收藏、阅读历史和筛选视图按账号存放在当前浏览器，清除网站数据或换浏览器可能不再显示。已失去权限或被删除的文件不会因为收藏而继续可读；收藏不等于取得授权，也不改变文件的问答范围。

也可以这样问：“收藏资料”、“我的收藏”、“继续上次阅读”、“最近阅读”。

<a id="knowledge-qa"></a>

### 知识库问答、选中文件与范围切换

资料库和经验沉淀均可勾选一个或多个项目、目录或可检索文件，再点“向所选范围提问”。项目和目录递归包含下级资料，重复选择自动去重；只包含当前有权访问、已完成索引的文件。一次最多1000份，超过上限要求缩小范围；空范围不会退回全库。未勾选时，“向当前目录提问”包含该目录下级资料，根目录“检索全部资料/经验”使用当前库可访问范围。目录范围在进入问答时解析为文件清单，此后新增资料需要重新选择。资料库与经验沉淀不能混选。
问答页点击“返回资料位置”，恢复提问前的目录、筛选、分页、布局、勾选和滚动位置。同一浏览器、同一账号会话内刷新后仍可返回；来源目录失效时回到有效上级。切换提问范围会开始新对话；单次问题控制在1500字以内，回答时再次检查当前权限。

也可以这样问：“RAG问答”、“知识库问答”、“选中资料”、“限定资料”。

<a id="knowledge-citations"></a>

### 引用核对、无结果与问答失败

知识库回答会展示检索/生成进度及引用，点击引用可阅读相关文件或片段并核对依据。同一文件的多个片段可能合成一个引用卡，仍保留各片段编号。没有找到资料支持时应缩小问题、核对文件范围、权限和索引状态，再补充材料，不能把无结果当成“事实不存在”。服务连接失败、超时和没有相关资料是不同情况，请保留错误提示；小助手可以教排查，但不会冒充已经读取了你的内部资料。

也可以这样问：“知识库引用”、“点击引用”、“没有检索到”、“知识库没有答案”。

<a id="knowledge-confidentiality"></a>

### 内部、机密与可见成员

保密等级只有内部、机密两类。正常普通账号默认可以使用知识库，但仅可读取内部资料；机密资料仅管理员可用。原“敏感”等级已统一合并为“机密”，已有资料不会因此对普通账号开放。内部资料默认共享，也可选择单独授权给创建人、管理员和指定账号；项目和行业标签不会授予权限。普通账号只能创建内部项目和文件，不能改为机密。创建人身份、旧授权和审批都不能突破保密等级。预览、下载、检索、问答与历史引用统一按此规则校验。

也可以这样问：“保密等级”、“敏感资料”、“机密资料”、“内部资料”。

<a id="knowledge-requests"></a>

### 申请访问权限与查看我的申请

在锁定资料上点“申请访问权限”，填写真实用途并提交；知识库右上角“我的申请”可查看审批中、已批准或已拒绝。审批中不要重复提交。被拒绝时按管理员说明补充原因或联系管理员；只有管理员批准后才会获得相应文件阅读权限。此申请流程仅适用于单独授权的内部资料；机密不向普通账号开放。小助手不能代替管理员批准。

也可以这样问：“申请访问权限”、“我的申请”、“权限申请”、“审批中”。

<a id="knowledge-approval"></a>

### 管理员审批文件访问申请（仅管理员）

路径：公司知识库 → 右上角“权限审批”。管理员查看申请人、文件、项目、保密等级和申请原因后，选择批准或拒绝，可按界面填写意见。已处理的申请不能再次处理；文件删除后不能继续批准。仅能批准内部资料的单独授权，不能通过审批向普通账号开放机密资料；历史申请在等级升级后也不能批准。小助手只说明流程，实际审批必须在管理界面操作。

也可以这样问：“权限审批”、“批准申请”、“拒绝申请”、“审批文件权限”。

<a id="knowledge-metadata"></a>

### 修改资料归类、复核状态与删除

上传者或管理员可在资料操作中编辑项目、行业、分类、复核状态、保密等级和可见成员，保存后应核对筛选和授权。待复核、已复核、参考资料是资料标记，不会因AI生成答案自动证明人工审核完成。同名不同内容会保留为新版本，默认问答使用当前最新版本，历史资料可按界面单独选择。同内容重复上传应查看原任务。删除资料会从资料库和问答索引移除，需页面确认；不要与删除研究任务或清空小助手聊天混淆。

也可以这样问：“编辑资料”、“资料信息”、“修改项目归属”、“修改复核状态”。

<a id="knowledge-chat-history"></a>

### 知识库对话历史与开始新对话

新版公司知识库的研究会话保存在服务器，按登录账号、知识库和资料范围隔离。同一账号连接同一套后端数据库时，刷新、退出重登或更换浏览器后，可从“研究历史”恢复已保存的会话。“开始新对话”保留旧历史；切换所选资料或“我的项目”等范围会建立新上下文，避免资料混用。“删除当前对话”经页面确认后删除该会话的消息、引用和摘要，不影响资料原件、其他研究会话或小助手历史。每轮仍按当前权限重新检索，历史回答不是事实依据；资料撤权、删除或版本变化后，相关历史可能隐藏。尚未发送的草稿属于当前页面内容；中断的回答按未完成显示，需查看已保存记录，不保证未完成内容恢复。知识库收藏、阅读历史和视图仍保存在当前浏览器；小助手与知识库分别管理各自的账号会话。

也可以这样问：“知识库聊天记录”、“知识库对话保存”、“知识库新对话”、“知识库历史消息”。

<a id="knowledge-projects"></a>

### 创建、编辑项目与继承属性

在资料库或经验沉淀点“创建项目”，填写名称、行业、分类、复核状态、保密等级、可见成员、标签与项目说明；创建后得到空项目目录卡片，可继续建立子目录和上传。资料库提供项目原件、研究成果、访谈纪要、行业资料；经验沉淀提供项目经验、案例复盘、方法与模板、培训分享、现场照片、手稿笔记、影音随记，分类按所在库定制。
文件和笔记继承项目属性及访问权限；普通账号可编辑自己创建的项目，管理员可管理。创建人、修改人由后端记录，不能手填冒用；“修改”指属性/目录等管理操作，不代表在线改写已上传的Word原文件。变更保留操作人、时间与前后内容，删除须按界面确认。 项目创建者和管理员可在“项目设置”底部点击“删除项目”，资料库和经验沉淀均支持。确认框列出全部版本资料、图文笔记和子目录数量；取消不会删除，内容变化需重新确认，正在处理或含无管理权限资料时阻止删除。确认后整个项目从知识库移除，页面不能恢复；原件、草稿和操作记录仅作为受控恢复副本保留。
项目、子目录和文件卡片的空白区域也可双击打开。连续上传后仍显示当前目录原有资料和新资料的处理状态，无需刷新；“完成，查看资料”不再隐藏之前上传的文件。

也可以这样问：“创建项目”、“新建项目”、“项目分类”、“空文件夹”。

<a id="knowledge-folders"></a>

### 子目录、面包屑与返回上一级

先打开项目，再点“新建目录”，新建的是当前所在位置的子目录。可按录音、访谈、照片等组织层级，文件保存在上传时选择的目录。顶部面包屑可点击父目录、项目名称或“项目空间”返回；“上一级”用于逐层返回。目录编辑及上传由项目创建者或管理员执行；非空目录不能直接按空目录删除规则处理。

也可以这样问：“新建目录”、“创建子目录”、“返回上一级”、“项目怎么返回”。

<a id="knowledge-locations"></a>

### 上传、新建笔记与随手记录保存位置

先看页面上方的项目名和面包屑。
1. “上传文件”：在当前项目、当前子目录归档。
2. “新建图文笔记”：在你有管理权限的经验项目中，保存在当前项目/当前子目录；停在经验沉淀根目录或当前项目不能管理时，会归入本人“随手记录 · 待整理”。
3. “随手记录”：无论当前浏览哪个目录，都固定归入本人“随手记录 · 待整理”，不会跟随当前目录。
例如在本人经验项目test根目录点“新建图文笔记”，就存入test；在test/录音里新建则存入test/录音。草稿已保存并不等于发布或可检索；不要把随手记录按钮与新建图文笔记混淆。小助手读取当前有权访问的目录后，可具体核对本次位置。

也可以这样问：“笔记保存在哪里”、“保存在哪个目录”、“新建笔记在当前目录吗”、“上传保存位置”。

<a id="knowledge-experience"></a>

### 经验沉淀、素材类型与跨库隔离

原“案例库”现为“经验沉淀”，用于保存未必是规范报告的一线素材：照片、手稿、录音、视频、复盘、方法与培训分享。可创建经验项目和子目录，上传原件、随手记录或新建图文笔记。照片/手稿可识别文字，正文/图片说明/经核对的识别文字参与检索；音视频只检索填写的说明，不自动转写。经验沉淀也做RAG，但检索、会话范围与资料库隔离，不自动跨库混搜。
经验沉淀的已发布内容对所有已登录、正常的企业成员可读，不再设置项目单独授权；修改和删除仍限创建者或管理员。未发布草稿不对其他成员开放。

也可以这样问：“经验沉淀”、“案例库”、“照片手稿”、“资料库和经验沉淀区别”。

<a id="knowledge-capture"></a>

### 随手记录与待整理收件箱

进入经验沉淀点“随手记录”，填写经验名称、适用场景和可复用做法，可附照片、手稿、录音或视频，也可以只写文字。保存时生成经验Markdown并归档附件；目标固定为本人“随手记录 · 待整理”，不是当前浏览目录。文字随现有解析/索引流程处理。若要在当前项目目录内长篇写作、插图和表格，请改用“新建图文笔记”；图文笔记有私有草稿与发布步骤。

也可以这样问：“随手记录”、“待整理空间”、“快速记录经验”、“只写文字记录”。

<a id="knowledge-notes-writing"></a>

### 图文笔记的创建与图文编辑

在经验沉淀 → 打开本人项目/目标子目录 → “新建图文笔记”。窗口中先填写笔记标题，点击正文纸面直接写作；上方可选择正文/一二三级标题、粗体、斜体、下划线、有序/无序列表、引用、表格和图片，支持撤销与重做。图片可选文件、粘贴截图或拖入。
本人经验项目内新建会沿用当前目录；未进入可管理的经验项目时，会归入本人“随手记录 · 待整理”。“我的笔记”可继续编辑保存的草稿。编辑器是图文笔记，不是上传Word的原位编辑，也不提供多人实时协作。

也可以这样问：“新建图文笔记”、“创建笔记”、“图文编辑”、“笔记怎么用”。

<a id="knowledge-notes-images"></a>

### 插图之后继续写正文与图片说明

插入图片完成后，光标会自动进入图片下方正文，可直接继续打字。若正在填写图片说明，说明框只写这张图的注释；按Enter或点图片下的“在图片下继续写正文”按钮，即可回到正文段落继续写，原说明会保留。中文输入法选字期间Enter不会跳走。正文不是图片说明框。图片右下角可拖动缩放，也可选择百分比；删除图片前注意保留需要的说明。

也可以这样问：“图片后怎么打字”、“插图后继续写”、“上传图片后继续写”、“图片下方正文”。

<a id="knowledge-notes-tables"></a>

### 笔记表格行列、合并与拆分

点工具栏“表格”先插入默认3行3列表格，不是只能3×3。先点击任意单元格，工具栏下会出现“下方加行”“右侧加列”“删行”“删列”“合并 / 拆分”“删除表格”。按Tab移动单元格；合并需先选中相邻单元格，拆分已合并单元格。单张表格上限100行、12列；超过限制请拆成多张表。表格可以在列表中使用；保存、Word导出和发布均保留表格结构。

也可以这样问：“表格只有3乘3吗”、“表格3x3”、“增加表格行列”、“表格怎么扩大”。

<a id="knowledge-notes-save"></a>

### 自动保存、失败重试与版本冲突

停笔约一秒后自动保存到服务器，顶部显示等待/保存中/已保存/失败状态；也可手动“保存”。关闭前会尝试保存，确认“已保存”后再刷新或离开。草稿还未发布时不会进入RAG。
保存失败时内容仍留在窗口，先不要刷新，点“重试保存”；仍失败可“下载本机副本”留存JSON恢复内容并反馈提示。本机恢复副本按账号与笔记保存，重开时可选择恢复，不保证浏览器缓存始终可用。
另一窗口改过同一篇笔记时会提示版本冲突，阻止覆盖；先保留本机副本，再“载入服务器版本”手动合并，不会自动覆盖别人的改动。“笔记格式不完整”是保存校验失败，不表示已经保存成功。

也可以这样问：“笔记保存失败”、“笔记格式不完整”、“草稿自动保存”、“重试保存”。

<a id="knowledge-notes-publish"></a>

### 发布笔记、索引更新与旧版保护

空白笔记或仅填写标题不能发布，先写正文或插入图片，发布按钮才可用。保存只更新私有草稿。点击“发布笔记”才生成不可变的归档Word并提交解析和索引；等右侧状态确认索引就绪后，正文才参与经验沉淀问答。尚未完成时不能说可检索。发布后继续编辑会改草稿，不立即替换其他成员正在读的版本；新版本索引成功才切换当前文件，失败时原先可检索版仍可用，可按右侧提示重试索引。草稿、发布修订和索引状态是不同概念。 提交成功会显示“已提交发布”，索引完成后显示“已发布”。响应丢失时先核对服务器状态；无法确认时显示“查询发布状态”，不重复提交。保存错误会明确提示尚未提交发布。

也可以这样问：“发布笔记”、“草稿会进入RAG吗”、“笔记为什么搜不到”、“重试笔记索引”。

<a id="knowledge-notes-ocr"></a>

### 笔记图片文字识别与手动校正

在笔记图片下点“识别图片文字”，识别后核对并在对应文字区域修正。已有校正内容时再次识别会先确认，避免覆盖。识别失败仍能手工写说明。标题、正文、表格、图片说明和经校正的OCR文字随笔记发布后参与检索；图片文件作为附件保留，不能保证AI仅凭图片就看懂所有业务细节。单张笔记图片支持PNG/JPEG/WebP，不超过12 MB和4000万像素，每篇最多100张。

也可以这样问：“识别图片文字”、“笔记图片OCR”、“图片说明检索”、“OCR识别失败”。

<a id="knowledge-notes-export"></a>

### 笔记导出Word与MD加图片压缩包

笔记右侧“导出当前草稿”提供“Word 文档”和“MD ＋ 图片”。先完成保存，导出时生成带当前账号、时间与追踪信息的副本。Word含可编辑正文、原生表格和内嵌图片；Markdown下载ZIP，内有note.md与images/，解压后保留相对路径，避免图片丢失。不要只取note.md而丢掉images目录。一次发布/导出参与的图片合计不超过32 MB；原件仍为私有存储，导出不解除项目权限。

也可以这样问：“导出笔记”、“笔记下载Word”、“MD加图片”、“Markdown压缩包”。

<a id="knowledge-notes-permissions"></a>

### 笔记权限、私有草稿与修改留痕

经验沉淀中已发布的笔记对所有正常企业成员可读；未发布草稿保持私有。未发布草稿仅项目创建者与管理员可读写；其他有阅读权限成员看到的是已发布快照，不能查看未发布草稿。创建人和最近修改人由后端自动记录；右侧“修改记录”显示最近100条操作，含操作人、时间与前后内容。普通账号不能编辑他人项目里的笔记；不提供多人同时实时协作，冲突时会阻止覆盖。
作者或管理员可从笔记编辑器或“我的笔记”列表单独删除笔记，确认框会显示标题、发布版本和配图数量。删除会移除草稿及全部发布版本，立即停止访问和检索；处理中的发布任务需先完成。经验文件也有独立删除入口和确认框，不必删除整个项目。

也可以这样问：“谁能看草稿”、“笔记权限”、“笔记修改记录”、“笔记继承权限”。

<a id="knowledge-download"></a>

### 原格式下载、水印与准备下载排查

阅读窗口点“下载水印副本”。下载和预览按格式生成包含账号、时间和追踪信息的副本，原始归档不被改写。现代Office与文字保留相应格式；Excel加背景和打印页脚标记，图片为带标记PNG，音频为含身份提示的MP3，视频为可见水印MP4。旧Office兼容处理或不支持的格式以实际提示为准，不能保证任何格式都直接返回。
“准备下载中”通常表示服务器在生成副本；媒体或大文档可能较慢。等待明确成功/失败，失败后按提示重试；不要不断重复点击。预览失败与下载失败不相同；系统不会在水印失败时偷偷返回无标记原件。

也可以这样问：“下载水印”、“为什么准备下载中”、“带水印下载”、“下载为什么是PDF”。

<a id="knowledge-theme"></a>

### 知识库主题、动画与玻璃窗口

知识库右上角主题图标可在浅色和深色之间切换，不影响系统其他业务页；旁边暂停按钮控制装饰动画。项目卡片、文件、弹窗、笔记与研究问答均使用对应配色，正文保持清晰纸面。主题在本浏览器保存，系统减少动态效果设置也会影响动画。

也可以这样问：“切换主题”、“白天晚上”、“浅色主题”、“深色主题”。

<a id="knowledge-search-content"></a>

### 搜索文件与阅读器内查找正文

资料库和经验沉淀的目录页使用文件名、项目及说明搜索，配合行业、复核状态和日期筛选；已移除“搜正文”切换入口。左侧分类切换会清除旧目录和旧正文搜索状态，同时更新实际内容。需要查文档内部文字时，打开文件，在阅读框内“搜索解析文字”；该查找覆盖可用解析片段并高亮命中，扫描件使用OCR结果，音视频仅检索填写的文字说明。页码可靠时可查看对应原文页。

也可以这样问：“搜正文”、“找文件”、“搜索不到文件内容”、“正文搜索”。

## 账号管理

仅管理员可进入。管理普通账号和管理员账号、角色专属邀请码、账号资料、停用归档恢复、密码重置和操作日志。

<a id="admin-users"></a>

### 管理员账号列表、搜索与资料编辑（仅管理员）

路径：左侧“账号管理”，仅管理员可进入。按页面标签查看普通账号或管理员，搜索用户名、显示名称和备注，并按启用、停用、已归档等筛选后翻页。“编辑资料”修改显示名称和备注，不更改登录用户名。知识库默认开通，普通账号仅可读取内部资料。管理员自己的账号区域在页面右上角，可修改自己的密码或退出登录。普通用户需要管理操作时请联系管理员。

也可以这样问：“账号管理”、“账户管理”、“管理用户”、“普通账号”。

<a id="admin-invitations"></a>

### 创建角色专属邀请码与有效期（仅管理员）

路径：账号管理 → 邀请管理。选择普通账号或管理员邀请、有效期，再生成并复制邀请码；默认有效期为六小时，每条只能注册一个对应角色账号。管理员邀请码的创建属于敏感操作，需要按界面验证管理员密码。邀请码只在生成时完整展示一次，列表不会再次返回原码，请当场安全保存并交给指定注册人。角色不能由注册人任意改选。

也可以这样问：“生成邀请码”、“创建邀请码”、“管理员邀请码”、“普通账号邀请码”。

<a id="admin-invite-cleanup"></a>

### 撤销、删除与过期邀请（仅管理员）

邀请码仍可使用时可以撤销，撤销后不能注册；已使用或已撤销的邀请可从列表删除。仍有效的邀请不能直接删除，先撤销；过期邀请会按系统清理规则处理。删除邀请只移除列表记录，不删除已经注册的账号，操作日志仍保留。原邀请码只在生成时展示一次，找不到原码时应重新生成，不能让小助手找回。

也可以这样问：“撤销邀请”、“删除邀请”、“邀请码过期”、“邀请已使用”。

<a id="admin-password-reset"></a>

### 管理员重置密码与二次确认（仅管理员）

路径：账号管理 → 目标账号 → 重置密码。按界面确认风险并输入你当前管理员账号的密码，系统生成临时密码，仅本次展示，请安全交给账号本人。重置会使对方原登录凭证失效，对方必须登录后修改临时密码。创建管理员邀请、重置密码、调整角色、停用和部分资格操作也可能需要二次确认；确认只对指定操作和目标短时有效，不能复制给别的操作使用。不要把管理员密码发给小助手。

也可以这样问：“管理员重置密码”、“重置用户密码”、“敏感操作”、“管理员密码验证”。

<a id="admin-status"></a>

### 启用、停用与知识库使用资格（仅管理员）

在账号管理的目标账号行按界面启用或停用。停用会阻止登录并使旧凭证失效，但保留任务、报告和历史数据；重新启用后需要重新登录。正常账号默认可用公司知识库，不再设置单独开通开关；普通账号仅能访问内部资料，机密仅管理员可用，内部资料的单独授权仍需满足。不能停用自己或破坏最后一名可用管理员，界面限制和后端检查都需要遵守。

也可以这样问：“启用账号”、“停用账号”、“知识库资格”、“授予知识库”。

<a id="admin-roles"></a>

### 提升管理员、降级与最后管理员保护（仅管理员）

路径：账号管理 → 目标账号的角色操作，按提示确认并验证管理员密码。提升和降级是独立操作，不能靠编辑资料里的任意角色字段绕过。角色变化会使旧凭证失效，目标账号需要重新登录；不允许对自己或最后可用管理员执行会破坏管理入口的操作。管理员可以访问机密资料；降为普通账号后仅能访问内部资料，旧授权不能突破等级限制。

也可以这样问：“提升为管理员”、“提升管理员”、“降级管理员”、“角色调整”。

<a id="admin-archive"></a>

### 账号归档、恢复与保留业务数据（仅管理员）

管理员先停用目标账号，再按页面确认“归档”。归档后账号默认从列表隐藏，任务、报告和历史资料保留；在“已归档”筛选里可恢复。恢复归档后仍保持停用，需要在未归档列表中另行启用才能重新使用。不能把归档理解成永久删除，也没有通过小助手删除全部账号数据的能力。

也可以这样问：“归档账号”、“恢复账号”、“恢复归档”、“已归档”。

<a id="admin-audit"></a>

### 操作日志与审计筛选（仅管理员）

路径：账号管理 → 操作日志。可按界面提供的操作者、目标账号、动作和时间条件查询并分页，核对邀请、账号状态、角色、密码重置和资料修改等管理事件。清理邀请后，日志仍保留必要历史，日志不会展示明文密码或原邀请码。小助手不能读取真实日志或判断某个账号具体是谁修改的，请在页面查询。
