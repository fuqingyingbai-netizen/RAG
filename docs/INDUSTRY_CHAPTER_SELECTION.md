# 行业报告章节选择

`backend/industry_chapters.json` 现在是运行时配置，不再是只读快照。前端通过 `/research/industry-chapters` 读取目录，后台从同一配置读取章节要求、固定研究问题与检索模块。`sections_explained` 仅帮助阅读，不规定输出小标题。

- 第2至13章可选择；第1、14、15、16章自动汇总。默认选择9个不依赖资本市场或指定企业的主体章节。
- 第8、9章须开启资本市场范围；第12章须填写核心企业名称。不满足条件时明确报错，不静默忽略。
- 新请求保存 `industry_chapter_ids`、`industry_template_version`，规范化范围保存 `selected_chapters`。空选择和未知编号拒绝执行。
- 章节编号稳定，例如只选第4章，目录为1、4、14、15、16，不重新编号。
- 检索方向可以共享，写作、问题规划、缺口修复、检查点恢复和结构校验按选择执行。选择前景展望仍可以检索规模、技术和政策材料。
- 旧项目无章节字段时保留原16章行为和已有研究模块，不反向猜测或静默缩减历史范围。历史报告不改写。
- 来源范围指纹不因单纯章节选择变化而失效；交付指纹包含章节选择及模板版本，防止第8、9章因共享检索模块而误复用报告。
- 综合评估保留既有风险评估边界；模型支持复核与技术测试不代表人工交付验收。

验证：新增章节配置、单章调度、研究依赖、兼容、输入拒绝、范围约束与指纹测试；前端加载、失败重试、请求和旧项目续跑测试；真实浏览器桌面/手机检查。行业全量回归失败项逐项对照既有基线，不能把既有失败表述为通过。

发布以线上源文件为基线，将本次行业差异合入共享文件，保留线上公司、人物及知识库实现。代码发布不迁移数据库、不修改原始资料或向量数据；激活前等待工作负载空闲，备份数据库和配置，保留前一发布目录用于回滚。
