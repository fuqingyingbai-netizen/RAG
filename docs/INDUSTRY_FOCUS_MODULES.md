# 行业重点模块与报告内容

前端选择研究重点，不选择交付章节。报告仍保留原有 16 章结构。

- 勾选：安排模块初始检索；章内有直接证据的问题优先写作；对应问题缺证据时允许有界专项补充。
- 未勾选：共享已有资料、执行相同写作与证据复核；不为普通问题追加专项检索。资料不足保留未解决缺口。
- 明确排除：资本市场关闭时不研究资本市场；未指定企业时不开展核心企业主体尽调。
- 辅助关联仅复用合适证据，不把关联章节自动升级为重点。证据准入规则保持不变。
- 全部取消：不恢复默认全选。仍可使用已有资料、用户指定检索和明确指定的核心企业任务。
- 历史检查点无重点策略时保留旧行为；新任务规范化后记录策略版本、重点模块。新策略不改变原始来源归属。

## 可检查配置

`backend/industry_focus_modules.json` 是实际运行映射：`primary` 为主要章节及其固定研究问题；`related_chapters` 为辅助关联，不能触发专项检索。空问题列表表示该章沿用独立写作路径（资本市场及核心企业），初始检索仍按模块与范围控制。

| 重点模块 | 主要对应内容 | 辅助关联 |
| --- | --- | --- |
| 行业定义与边界 | 行业基础中的定义、产品及应用 | 统一口径 |
| 细分赛道与产业链 | 产业链分层、价值分配、瓶颈 | 竞争、投资机会 |
| 政策与监管 | 政策原文、规划、准入、义务、日期与执行 | 热度、前景、风险 |
| 市场规模与增长 | 规模口径、增长、历史序列、预测与驱动 | 热度、投资机会、前景 |
| 竞争格局与代表企业 | 玩家、份额、五力与护城河 | 投资机会、指定核心企业 |
| 商业模式与盈利逻辑 | 投资机会中的收费、盈利、赛道筛选 | 竞争 |
| 技术演进与平台生态 | 技术路线中的适用场景、迭代成熟度 | 竞争、前景 |
| 技术路线对比 | 路线、测试条件、性能及单位成本 | 投资机会、风险 |
| 投融资与资本市场 | 行业投融资、二级市场情绪 | 热度、投资机会 |
| 行业风险与不确定性 | 风险机制、经营研发风险、监管义务 | 综合评估 |
| 核心企业尽调（填写企业触发） | 指定企业主体尽调 | 竞争、投资机会 |

执行记录：研究计划 `focus_module_mapping`，写作诊断 `research_depth`，补充研究 `deferred_research`。不补充的缺口不能标记已解决。所有方向仍执行原来的格式、数值、引用、质量及原文支持核验。
