# 小助手截图问答

小助手统一使用阿里云百炼 `qwen3.5-flash` 处理文字聊天、截图识别与记忆摘要，没有按图片/文字切换两套模型。精确的本地操作指引仍可直接返回，不额外请求模型。研究报告、OCR及公司知识库的原有模型配置不变。

## 使用方法

1. 打开任意页面的小助手，在输入框上方点“＋ 添加截图”，或在输入框中粘贴剪贴板图片。
2. 发送前可看缩略图，点图片右上角“×”移除。最多2张，单张不超过3 MB，支持静态PNG、JPEG、WebP。
3. 补充问题，例如“为什么这个文件不能勾选？”或“怎样只对我选中的文件提问？”。也可仅发送截图；目标不明确时会要求补充。
4. 模型提取清晰的页面、按钮、报错文字，后端再核对已有系统指南，返回使用说明。截图模糊、无关、含多个可能目标或未能确认功能时澄清，不猜按钮或声称完成操作。

## 保存与边界

- 原图只随本次已登录请求发送给配置的阿里模型，不写数据库、对象存储、知识库或研究溯源库，也不向公开搜索工具发送截图。
- 页面保留本次发送的缩略图；刷新、切换账号/会话或重新加载后不恢复图片。服务器保存用户问题、附图数量说明、识别成功时的短文字摘要和操作答复，便于续聊；需要重新核对图像时请重发。
- 图片识别属于可能出错的观察，不能证明后台真实状态，不应替代实际权限校验。按当前登录角色提供指南；管理员页面的截图也不会授予管理员步骤或权限。
- 解析后最大边长1600像素、最多1200万原始像素；拒绝伪造格式、外部图片网址、动画与破损图片。服务器重新编码并去除元数据，限制图片输入成本。
- 截图及其文字均作为待分析数据，不能覆盖系统规则。不要发送密码、密钥或令牌。
- 新建会话、重新加载、退出登录会清空待发送图片。异步文件读取带账号/草稿代次检查，迟到结果不能进入另一个账号。

## 配置

```dotenv
ASSISTANT_MODEL=qwen3.5-flash
# 默认沿用现有 ARK_API_KEY 和 BASE_URL，不需要新密钥。
ASSISTANT_API_KEY=
ASSISTANT_BASE_URL=
```

三项仅作用于小助手。配置变更后重启后端。非思考模式、最多1800输出token、截图识别最多900输出token，默认不重试；图片请求只做一次结构化识别，再由本地指南返回步骤。

截至2026-10-20，官方全球部署报价中，`qwen3.5-flash` 单次输入不超过128K时，输入0.2元/百万token，输出2元/百万token；图片也会计入输入token。以账号实际部署范围与账单为准，见[官方计费说明](https://help.aliyun.com/zh/model-studio/model-pricing)。本项目实测现有API可用，已验证文字、图片和Function Calling。

代码入口：`assistant_model.py`（统一模型）、`assistant_images.py`（临时图片校验与指南定位）、`research_api.py`（保存文字与SSE）、`frontend/script.js`（选图/粘贴与草稿隔离）。
