# 公司功能与行业分支集成验证

本轮先保存公司知识库未提交的“我的项目、保密等级、权限申请审批”改动，合入远端 main（771341c），完成新功能与本地验收并推送公司分支，再合入 `feat/industry-report-optimization`（e4927d5）验证。

## 最终行为

- 右下角小助手提供基于实际页面和角色的系统使用说明、导航快捷入口及一般文字聊天，不调用项目资料、报告和向量检索。公司知识库页面也可使用，换账号不继承上一账号聊天。业务资料问答仍由公司知识库承担。
- 第一阶段报告保存后，以创建人的稳定账号 ID 自动归入公司知识库研究成果，关联原任务和报告版本。默认 restricted、待复核；普通其他账号不能直接阅读。归档幂等，索引异步进行，失败可重试，不影响报告下载。任务管理显示实际索引状态。
- 最新报告版本进入默认问答范围，历史版本可显式选取。人工复核状态随知识目录展示和引用。账号仍需获得公司知识库使用资格。
- 新采集网页及专业平台原始正文用于本轮研究和中断续跑，成功结束后清理对应正文及原始对象，保留来源记录、查询定位、短摘录和报告证据产物。历史记录、上传原件和报告不会自动批量删除。失败任务保留临时资料，清理异常在 trace 中提示。
- 溯源库不再读取对象存储全文来展示列表；提供原始链接和平台查询记录。公开链接可能失效或需要登录，不将 `structured://` 当作公开网页。
- 保留 main 的可折叠尽调工作台导航，以及行业分支新增的证据台账、风险证据覆盖、待复核原因和降级说明。
