# 企业知识库易用性优化验收

目标：完成用户提出的八组交互问题，并统一为白灰内容区、清晰导航、连续列表和实色弹窗。

| 项目 | 实现与验收条件 |
| --- | --- |
| 项目加载 | 本地目录优先返回，云端发现后台执行；项目和文件并行，文件分页最多三路并发；取消进入目录的固定等待 |
| 返回上级 | 明确的“返回上一级”按钮、可点击祖先面包屑、不可点击当前目录；目录进入不保留旧正文搜索和筛选 |
| 筛选精简 | 更多筛选仅保留日期范围；删除目录页正文搜索入口及结果区域，保留阅读器内部查找 |
| 项目/目录/文件提问 | 支持多选项目、目录和文件的并集；目录递归包含下级；服务端校验当前权限、库边界和索引状态；空范围明确报错，不能退回全库 |
| 返回原位置 | 提问前记录来源目录、筛选、分页、布局、勾选和滚动位置；问答页“返回资料位置”；同一用户会话内刷新后保留来源；来源失效回退到有效上级 |
| 经验共享 | 所有正常成员可以阅读已发布经验；创建者/管理员可修改和删除；未发布草稿仍私有；资料库原有权限不受影响 |
| 管理入口 | 项目“设置”文字和箭头；非管理者标注“只读”，保持后端删除权限检查 |
| 目录与导航 | 即时进入唯一目录；有子目录但没有直属文件时不显示误导性的空文件提示；分类切换同时更新内容和选中状态 |
| 视觉收敛 | 白灰内容、深色正文、品牌蓝操作；连续项目行；首页常用项目代替知识星图；实色轻阴影弹窗；移除持续装饰动效 |

## 验证方式

- 后端：使用隔离 SQLite 测试项目、目录并集、权限撤回、跨库拦截、私有草稿、共享经验、云同步等待等；上线前还需在服务器恢复的隔离 PostgreSQL 副本复测。
- 前端：保留原上传、预览、会话、读取取消回归，新增导航、来源返回、失效来源、迟到响应和并发加载回归。
- 浏览器：使用本地隔离测试目录验证实际点击、目录多选、超过 20 份资料的提问范围、三级目录第 2 页返回、分类切换、深色与手机布局。
- 测试方法参考 [Playwright 官方最佳实践](https://playwright.dev/docs/best-practices) 与 [测试隔离](https://playwright.dev/docs/browser-contexts)：按可见行为断言、隔离数据、等待状态而非固定睡眠。

## 边界

一次显式选择最多 1000 份已完成索引且有权限的资料；超过上限要求缩小范围，不截断、不扩大范围。
后续回答继续重新校验资料权限。目录范围在进入问答时解析为文件清单；此后新增文件需要重新选择范围。
“所有成员可读”指已登录、正常的企业成员；不提供匿名公开访问。没有把阅读权限变成删除权限。
