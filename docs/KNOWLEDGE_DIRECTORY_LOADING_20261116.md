# 知识库目录加载反馈修复

用户反馈：进入“上传失败体验（测试，可删除）”后，子目录先出现，文件区域空白一段时间才出现文件。

## 原因与范围

前端先收到项目与子目录，再分批读取资料目录；全部分页结束后统一更新文件列表。旧模板在“已有子目录、文件尚未返回”时隐藏整个文件表格，因此等待期间没有文件列表加载提示。这次诊断的接口均成功，未观察到文件丢失。

一次公网只读测量读取866条资料、9页：首个资料请求880毫秒，各页811–1619毫秒，按现有并发方式全部分页耗时5311毫秒，项目列表请求2979毫秒。数据包含客户端公网往返时间，属于单次样本，不是服务端P95，也不是每次进入目录都会再次读取9页。

本次只修改目录表格的加载反馈和样式，不改变资料查询、全量分页、目录筛选、选择、上传、阅读、权限和积分逻辑。

## 现在的表现

- 文件列表未返回时显示“正在加载当前目录的资料，请稍候…”、旋转指示和占位条；有子目录时也保留加载状态。
- 刷新时保留已经加载的文件，显示“正在更新资料，已加载的内容仍可查看…”。
- 加载中不提前显示“暂无资料”；成功、空结果、接口失败均结束加载状态，失败沿用已有错误提示。
- 状态通过`role=status`提示辅助技术，表格设置`aria-busy`；减少动画模式停用旋转与脉冲。提示颜色使用现有明暗主题变量，深色模式文字对比度通过4.5:1检查。

首次加载所需的接口等待时间仍存在；本次解决的是等待期间空白且没有提示的问题。
