## 指标的实际限制

- Ragas 事实 F1 不等于业务准确率。本题集有些参考答案只列必要要点、未写对象名称；Q038 原始审计显示，正确的时间和数值因补入对象/报告名，被 NLI 判为参考之外的声明，F1 和原生 recall 均为 0。零分保持原样。
- Ragas 0.4.3 原生 recall 的 TP 仍来自回答声明到参考的支持判断，不是简单的必要要点命中比例，受声明拆分影响。
- Faithfulness 输入为证据正文，未加入标题、版本、复核状态和引用编号映射。引用探针原始审计中，Q032 的标题/问题时间、Q082 的来源编号单元格、Q093 的问题隐含对象名受到该限制；Q082 还有真实存在的摘录措辞问题。不能把探针等同于逐句引用准确率，也不能用这些解释删改低分。
- 生成与评分使用同一型号模型，有同源偏差。Q020 自动忠实度为 1.0，原文复核仍识别出过度判断；因此高分也不替代业务抽检。
- 固定片段上的 ContextRecall=1.0，仅说明评分器认为这些片段覆盖参考事实，不能称作全库实时召回率 100%。
