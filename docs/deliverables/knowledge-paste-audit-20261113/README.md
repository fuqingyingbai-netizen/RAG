## 已交付

- 点击粘贴立即显示临时文件行，依次显示检查权限、创建副本／保存位置；权限确认取消时移除临时行。
- 后端确认后立即插入真实文件并提示成功，目录刷新不再阻塞成功反馈。索引继续在后台执行，明确显示“文件已保存，正在建立检索索引”；索引失败提供原有重试入口。
- 网络中断时显示“保存结果尚未确认”，重试沿用原请求编号；复制成功后的标记改为“已复制，可继续粘贴”。
- 知识库操作记录仅显示最近 10 天（240 小时），后台每分钟最多清理 500 条过期记录。管理员可逐条删除，删除前确认；普通成员保留原有查看权限，不能删除。
- 新增独立的最小请求防重凭据表。旧记录手动删除或过期清理时，先在同一事务中保存必要凭据，再删除操作记录；不保留完整操作变更内容。删除日志不删除资料，也不会使复制重试生成重复文件。
