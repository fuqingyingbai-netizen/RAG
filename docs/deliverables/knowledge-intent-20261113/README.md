## 改动

- 检索前统一分流，有会话和无会话入口均覆盖。纯问候、致谢等直接回复；系统操作问题提示前往 AI 助手，不加载系统指南。
- 明确业务问题直接沿用检索流程。复杂表达的意图识别与追问补全合并在一次模型请求中，校验 JSON、意图、对象与指标；仅格式校验失败允许一次修正。
- “谢谢”“在吗”等不覆盖当前业务任务；新对象更新任务。格式追问、资料权限、会话归属、失效历史过滤和回答引用校验继续执行。
- 独立问题的分类服务异常时保守进入资料检索；依赖上文的未解决问题不会偷偷复用旧对象，也不会被降级成闲聊。
- 日志记录意图、规则或模型来源、耗时、错误类型、是否实际发起检索。日志不包含完整问题、资料正文或凭据。
