# 知识库文件复制、剪切与版本验收（2026-11-13）

代码提交：`bc8d59e7c2fc2ac668884aa71239518d34abd3a1`，已推送 main 并发布至生产。

已实现：

- 单文件右键复制／剪切／粘贴；提供菜单按钮、Ctrl+C / Ctrl+X / Ctrl+V、Shift+F10 和 Escape。文本框保留正常编辑行为。剪切成功清空标记，复制可继续使用。
- 剪切沿用移动接口，修改归档位置并携带未删除的历史版本；复制仅取最新版本，新建记录和独立云端索引，初始共享受控原件。
- 同名复制自动添加“（副本）”“（副本2）”；移动遇到同名文件拒绝覆盖。重复上传根据 SHA-256 判断：相同内容另存副本，不同内容保留下一版本。
- 主列表及默认问答只使用最新版，历史窗口保留旧版本。显示和下载名称包含 `_V1` / `_V2`；编辑下载文件再上传可归回原版本系列，包括导出的水印文件名。
- 粘贴重新校验登录、源文件快照、管理权限、目标写入权限及处理状态；目标权限改变必须确认。目标项目继承归档属性，部门根目录遵循选定部门，重复上传私有资料保留访问限制。资料库与经验沉淀保持边界。
- 通过事务内审计收据实现请求防重，记录复制人、来源版本和时间；复制索引失败可以独立重试。共享原件引用的新增与最终回收使用同一事务锁，回收时检查其他文件、历史／回收站记录与笔记附件。
- 检索先执行权限与目录范围过滤，再按内容合并相同副本，避免同一资料重复占用检索名额。
