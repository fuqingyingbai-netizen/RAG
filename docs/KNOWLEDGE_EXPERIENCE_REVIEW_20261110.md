# 企业知识库业务流程检查（2026-11-10）

本轮范围是公司知识库。规则来自当前产品约定：资料库与经验沉淀分开；项目创建者及管理员可新增和管理；其他成员只读；已发布经验对正常成员可读，未发布草稿私有；显式提问范围不能自动扩大。

## 页面业务规则

通过 computer-use 的浏览器 Playwright 接口实际操作独立的本地验收站点。没有使用正式业务数据进行创建或删除。共检查 30 条规则；3 条在首轮失败，修复后重新通过。

| 流程 | 核对条件 |
| --- | --- |
| 总览 → 项目 → 子目录 | 目录内收起总览筛选，路径与内容一起切换 |
| 当前目录内搜索 | 包含当前目录及下级，排除同级分支、项目根目录和其他项目 |
| 目录名称搜索 | 能找到范围内的子目录，清空后恢复原层级 |
| 多页资料提问 | 第三级目录第二页选择两份资料，实际请求仅包含这两份 |
| 刷新和返回来源 | 恢复问答范围；返回原目录、第二页及勾选 |
| 左侧分类 | 退出旧目录并更新内容，不能只改选中颜色 |
| 只读项目 | 新建、上传禁用，并显示原因 |
| 收藏 | 收藏可从“我的收藏”进入；计数随资料库/经验沉淀分别计算 |
| 经验阅读 | 普通成员能阅读他人已发布经验，管理入口仍受限 |
| 新建与上传 | 在项目内创建两级目录，实际上传到当前子目录，完成后仍在该目录 |
| 删除与恢复 | 取消删除保留文件；确认后进入回收站；恢复后回原目录 |
| 完整原件 | 原件独立可读，不能将检索片段数当作原件页数 |
| 账号切换 | 研究历史按账号隔离，管理员可管理其他人的项目 |
| 多项目提问 | 递归合并为 27 份可读资料，展开清单完整，排除私有文件 |
| 经验个人工作区 | 我的笔记含本人草稿和经验文件，已发布图文笔记去重；收藏和失败列表不混入资料库 |
| 经验失败恢复 | 保存的原件可直接重试；重传锁定原项目、目录、名称；缺失原件补传保留原记录 |
| 表单焦点与边界 | 随手记录、新建项目左边框和聚焦样式完整；共用弹窗规则覆盖其他表单 |
| 问答范围文案 | 未选择资料时显示全库提问，选择后显示所选范围 |

页面浏览器控制台未出现错误。窗口大小使用当前默认值，本轮没有额外宣称完成跨浏览器或全设备兼容测试。

## 接口与连续操作

使用 Schemathesis 4.33.1 对隔离 API 执行覆盖、模糊输入及状态测试。首轮生成 942 个用例，发现 3 个 422 响应契约错误；修正共享错误响应定义后，复跑 5,250 个生成用例通过。

自动生成报告仍提示：部分操作缺乏有效资源 ID，部分业务限制比字段定义更严格。随机请求返回 404 不等于验证了真实流程。因此另外使用 Schemathesis `Case.call` 和响应校验执行了 **27 条明确的连续业务检查**，覆盖创建项目、重复名称、逐级目录、只读越权上传/创建、实际上传、重复内容、递归范围、跨库拒绝、私有会话、私有草稿、非空目录删除拒绝、回收站恢复、停用及匿名账号。

本地验收保留真实路由、权限、数据库和会话。云端解析、模型回答等外部服务使用桩，不把这些结果当作云端质量或安全审计结论。

## 已修复

1. 子目录搜索曾扩大到整个项目，可能混入同级目录文件；现在按目录子树限制。
2. 输入子目录名称曾隐藏全部目录；现在支持范围内目录名称匹配。
3. “我的收藏”曾使用跨库总数；现在与当前库的收藏列表一致。
4. 全库问答欢迎标题曾固定写“向所选资料提问”；现在根据当前范围显示。
5. 422 接口说明仅声明数组，实际业务错误会返回文本；现在明确声明两种合法错误结构，保持现有客户端兼容。
6. 阅读侧栏补充“片段数不等于原文页数”，避免误解解析覆盖范围。

7. 经验个人区改为“我的笔记”，包含本人图文草稿和文件；已发布图文不重复计数。个人问答使用 `my-experience`，仅有草稿时提示先发布，不扩大范围。图文笔记发布后可收藏、阅读已发布版本；分类切回“我的笔记”清除旧分类条件。
8. 经验创建入口集中对齐，草稿改为连续列表；修复弹窗输入框边缘焦点线被裁切。
9. 失败文件增加重新上传入口，锁定原项目、目录与名称。原件缺失走补传修复；内容变化形成新版本，旧失败记录保留，可由有权限的人移入回收站。相同内容直接重试处理。

新增搜索范围、收藏计数、个人范围及原路径重传回归测试。前端 86 项、相关后端 97 项回归通过。

## PPTX 实文件核对

## 重复执行

`scripts/manual/knowledge_audit_app.py` 只监听回环地址，并阻止外部服务连接。必须使用专门的测试目录。浏览器和 API 模糊测试分别使用独立目录及端口，避免随机写入影响页面用例。

```powershell
python scripts/manual/knowledge_audit_app.py --data-dir work/audit-ui-data --port 8891
python scripts/manual/knowledge_audit_app.py --data-dir work/audit-api-data --port 8892
```

工具依赖独立安装，不修改业务运行环境：

```powershell
python -m pip install --target work/knowledge-audit-tool-libs -r scripts/manual/requirements-knowledge-audit.txt
python scripts/manual/check_knowledge_business.py --url http://127.0.0.1:8892 --tool-libs work/knowledge-audit-tool-libs --report work/knowledge-api-business.json
```

浏览器按上表逐项执行并等待可见状态；上传使用独立的无敏感内容文本文件。恢复、删除和随机测试只运行在上述验收站点。

方法参考：[Playwright 用户可见行为与隔离测试](https://playwright.dev/docs/best-practices)、[Schemathesis Python API](https://schemathesis.readthedocs.io/en/stable/reference/python/)。
