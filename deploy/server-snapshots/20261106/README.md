# 2026-11-06 服务器运行代码的恢复快照

清理历史部署前，发现运行代码与主分支存在差异。因此单独保留源码快照，避免清理时丢失服务端独有改动。本快照是代码备份，不代表把这些功能改动重新合并、验收或部署到主程序中。

- `manifest.json` 记录基线 Git 提交、运行实例、308 个运行源码／资源文件的 SHA-256 和覆盖包校验值。
- `runtime-overlay.zip` 保存与基线不同或仅存在于服务器的文件；不含账号密钥配置、业务原件、数据库、向量索引或 Python 依赖。
- 已在本地重建基线并覆盖 ZIP，逐项核对全部文件哈希一致。

恢复时先新建隔离目录，检出 manifest 中的 `base_commit`，校验覆盖包 SHA-256，再将 ZIP 解压覆盖到该隔离目录。逐项核对 `file_sha256` 后再开展兼容、测试与发布。不要直接覆盖当前生产服务。

仅有源码快照不能恢复业务数据；数据与配置备份仍需独立保留。清理过程中运行服务、共享数据和现有运行依赖均保持不变。
