# 新增原文记录的语义复核清单

类型转换后恢复的是可供后续审稿的原文记录，不是已经独立核实的经营结论。以下项目依据开发样本的实际新恢复记录建立，尚未核对最终报告是否采用，也不用于生产提示词或补写报告事实。

| 来源 | 需要在最终正文核对的含义与限制 |
| --- | --- |
| 81、135、147、169、190、197、202、232、238、245 | 区分标准计划、已发布文件与即将实施状态。列为起草单位不等于认证、实际合规、技术独占或行业排名；标题与完整单位名单须属于同一连续原文。 |
| 29 | 外部标准化技术委员会履历中的工作单位、职务、加入日期分别归因；不能当成公司董事会任职或实际任职起始日期。 |
| 116 | 员工持股计划的锁定期以宣布完成股份过户等原条件起算；计划规则不证明过户已经完成，也不提供实际锁定日期。 |
| 176 | 留存文件正文明确为 **2022 年年度报告**。报告期“无重大诉讼”等公司披露不等于研究截至日没有任何案件；不抹去其他时期具体诉讼。 |
| 176 的信用减值条款 | 会计政策和“哪些情形构成信用减值”的条件列表，不证明公司、债务人已发生违约或财务困难；条件、方法与实际金额分别处理。 |
| 254、301 | 两个域名下的相同原件可交叉佐证，不重复累计金额。部分留存表头/列关系有错位，正文若要使用具体期限或金额须回到原页核对；不能靠猜列补数。 |
| 254、301 的经销商贷款 | 原文借款服务由关联方嘉兴海天提供，且披露本集团不向经销商提供担保；不能将关联方服务改成目标集团放款或承担担保责任。 |
| 437 | “融资买入”“融资余额”等为证券市场两融数据，不是公司取得融资或银行到账。原文只有月日时，不从 URL 或常识补出事件年份。 |
| 433 | 第 39 类商标申请、服务项目及历史期限按第三方页面归因。申请不等于已注册、仍有效或已续展；核定服务分类也不证明公司实际经营运输业务。 |
| 74 | 正文页眉明确为 **2025 年年度报告**。全年现金流不能直接与 2026 年半年度金额算同比；须保留 2026 半年报自己的上年同期、调整列及现金流解释。 |
| 其他恢复记录与镜像 | 来源、主体、期间、单位、计划/完成与限制保持原样；副本及同一事件的不同来源不当成独立经营事件，记录增加不等于报告质量已经提升。 |

最终人工/独立复核记录应绑定实际候选 ID、正文及导出 SHA256，说明这些项目在正文、表格、图谱、附件或待核清单中的真实去向。若正文未采用，记录具体理由；若原件关系不足，保留缺口，不把格式失败写成没有资料。最终候选尚未形成，本清单各项均未冒认通过。
